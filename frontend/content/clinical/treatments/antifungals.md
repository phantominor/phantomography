## 抗黴菌藥物總論

- 黴菌是**真核生物** → 可打的目標比細菌少；主要打人類沒有的 **ergosterol**（人類是 cholesterol）與**細胞壁**。

| 作用位置 | 藥物 | 機轉 |
|----------|------|------|
| **細胞膜** | **Polyenes**（Amphotericin B、Nystatin） | 結合 **ergosterol** → 膜上打洞 |
| **Ergosterol 合成** | **Azoles** | 抑制 **14α-demethylase**（lanosterol → ergosterol） |
| | **Terbinafine** | 抑制 **squalene epoxidase** |
| **細胞壁** | **Echinocandins** | 抑制 **β-(1,3)-D-glucan synthase** |
| **核酸合成** | **Flucytosine** | 轉成 5-FU → 抑制 DNA/RNA 合成 |
| **有絲分裂** | Griseofulvin | 干擾微小管 |

### 各菌選藥（Spectrum）

| | Fluconazole | Vfend | Noxafil/Cresemba | Echinocandins | AmB |
|--|-------------|-------|------------------|---------------|-----|
| **C. albicans** | 有 | 有 | 有 | 有 | 有 |
| **C. glabrata** | 劑量依賴/抗藥 | 不穩定 | 不穩定 | **有** | 有 |
| **C. krusei** | **天生抗藥** | 有 | 有 | **有** | 有 |
| **C. auris** | 多抗藥 | 不穩定 | 不穩定 | **首選** | 部分抗藥 |
| **Cryptococcus** | 有（鞏固、維持） | 有 | 有 | **無效** | **有（誘導）** |
| **Aspergillus** | **無效** | **首選** | 有 | 救援、合併 | 有 |
| **Mucorales** | **無效** | **無效** | **有** | **無效** | **首選** |

- **Fluconazole 不涵蓋黴菌（mold）**；**Voriconazole 不涵蓋 Mucor**。
- **Echinocandins 對 Cryptococcus、Mucor 無效**。
- 天生抗 AmB：**C. lusitaniae**、**Aspergillus terreus**。

## Polyenes（多烯類）

### Amphotericin B

- 機轉：結合 **ergosterol** → 細胞膜形成孔洞 → 離子外漏 → **殺菌**；最廣效的抗黴菌藥。
- 劑型：
    - **Conventional（deoxycholate）**：便宜、毒性大。
    - **Liposomal（AmBisome，L-AmB）**：**腎毒性、輸注反應明顯較少** → 目前主流。
- 適應症：
    - **[[神經內科#隱球菌腦膜炎|隱球菌腦膜炎]]誘導期**：**L-AmB + Flucytosine** × 2 週 → Fluconazole 鞏固 8 週 → 維持至少 1 年。
        - HIV（WHO 2022）：**單次高劑量 L-AmB 10 mg/kg** + Flucytosine 與 Fluconazole × 14 天。
    - **[[感染科#Mucormycosis|Mucormycosis]]**：**L-AmB 5–10 mg/kg** + **緊急清創**。
    - 嚴重地方性黴菌（Histoplasma 等）、其他藥物無法使用的侵襲性念珠菌或麴菌感染。
    - **懷孕**的全身性黴菌感染（最安全）。
- 副作用：
    - **輸注反應**（**shake and bake**）：發燒、寒顫、低血壓 → 前給 Acetaminophen、Antihistamine、Hydrocortisone，**減慢滴速**。
    - **腎毒性**：入球小動脈收縮 + 腎小管損傷 → **給藥前補生理食鹽水**；避免併用其他腎毒性藥物。
    - **低血鉀、低血鎂**（**第一型遠端 RTA**）→ 每天驗電解質、積極補充。
    - 貧血（EPO 減少）、靜脈炎。
- 不需依腎功能調整劑量（但腎毒性時要考慮換劑型）。

### Nystatin

- 機轉同 AmB；**毒性太大不能全身使用** → 只做**局部**。
- 口腔念珠菌（**鵝口瘡**）漱口吞服、皮膚念珠菌外用。

## Azoles（唑類）

### Azoles 總論

- 機轉：抑制黴菌 CYP450 的 **14α-demethylase** → ergosterol 減少、毒性中間產物堆積 → 對 Candida **抑菌**、對 Aspergillus **殺菌**。
- 共同問題：
    - **CYP3A4 抑制** → 大量交互作用（Tacrolimus、Cyclosporine、Statin、Midazolam、Warfarin、Vincristine 等）。
        - 抑制強度：Ketoconazole、Itraconazole、Voriconazole、Posaconazole **強**；Fluconazole、Isavuconazole 中等。
    - **QT 延長**（**Isavuconazole 例外，反而縮短 QT**）。
    - **肝毒性** → 追蹤肝功能。
    - 懷孕避免（致畸）。
- 抗藥：*ERG11* 突變、外排幫浦（CDR、MDR）。

### Fluconazole

- **口服吸收接近 100%**；**CSF、尿液、眼睛穿透好**；經腎排除 → 依腎功能調整。
- 涵蓋：**Candida**（不含 C. krusei，C. glabrata 不穩定）、**Cryptococcus**、Coccidioides；**沒有黴菌（mold）活性**。
- 適應症：
    - **[[婦科#常見陰道感染比較|陰道念珠菌感染]]**：**150 mg 單次**口服。
    - **食道念珠菌感染**：14–21 天。
    - **念珠菌血症降階**：病況穩定、菌株敏感 → 由 Echinocandin 改口服 Fluconazole。
    - **念珠菌泌尿道感染**（有症狀或要接受泌尿手術）：Echinocandin 尿中濃度低，這時用 Fluconazole。
    - **隱球菌腦膜炎**鞏固期（400–800 mg）與維持期（200 mg）。
    - 預防：骨髓移植、高風險加護病人。
- 副作用相對少：肝功能異常、QT 延長；高劑量時交互作用變明顯。

### Itraconazole

- 涵蓋：Candida、**Aspergillus**、**地方性二型性黴菌**（Histoplasma、Blastomyces、Talaromyces 維持治療）、**[[感染科#Sporothrix schenckii|Sporotrichosis]]**、皮癬菌。
- 適應症：
    - 地方性黴菌輕中度、Sporotrichosis **首選**。
    - **甲癬**（脈衝療法）、皮癬菌感染。
    - **ABPA**：合併類固醇，減少類固醇用量。
- **吸收不穩定**：
    - 膠囊**需胃酸 + 隨餐**（避免 PPI）；口服液**空腹**。
    - **TDM** 驗血中濃度。
- 副作用：**負性肌力** → **心衰竭禁用**；低血鉀、高血壓、水腫（類礦物皮質素作用）；強 CYP3A4 抑制。

### Vfend（Voriconazole）

- **[[感染科#Aspergillus|侵襲性麴菌症]]首選**。
- 其他：Fusarium、Scedosporium、Fluconazole 抗藥念珠菌（C. krusei）。
- **沒有 Mucor 活性** → 長期使用時出現**突破性白黴菌感染**。
- **CYP2C19 基因多型**：**東亞慢代謝者約 15–20%** → 濃度差異大 → **TDM**（trough 約 1–5.5 μg/mL）。
- 副作用：
    - **視覺異常**（短暫光暈、色覺改變）：約 30%，開始用藥時常見，多會消失。
    - **幻覺**、意識改變（濃度過高）。
    - **光敏感** → 長期使用增加**皮膚鱗狀細胞癌**風險 → 防曬。
    - **骨膜炎**（含氟 → 氟中毒）：骨痛、ALP 上升。
    - 肝毒性。
- IV 劑型溶劑（SBECD）經腎排除 → **CrCl < 50 優先用口服**。

### Noxafil（Posaconazole）

- 涵蓋：Candida、Aspergillus、**Mucorales**。
- 適應症：
    - **預防**：**急性骨髓性白血病、骨髓化生不良症候群**化療誘導期的嗜中性球低下、**GVHD** 使用強效免疫抑制者。
    - Mucormycosis 的**降階或救援**治療。
- 延釋錠**隨餐**服用，吸收較穩定；TDM。
- 強 CYP3A4 抑制、QT 延長。

### Cresemba（Isavuconazole）

- 涵蓋：Aspergillus、**Mucorales**、Candida。
- 適應症：**侵襲性麴菌症**（療效與 Voriconazole 相當，副作用較少）、**Mucormycosis**。
- 優點：
    - **QT 縮短**（而非延長）→ 長 QT 病人可用；**先天性短 QT 症候群禁用**。
    - 交互作用、肝毒性、視覺副作用較 Voriconazole 少。
    - 線性藥動學、**IV 不含 SBECD** → 腎功能差可用 IV。
    - 一天一次（前 48 小時 loading q8h）。

### 外用 Azoles

- **Clotrimazole**、**Miconazole**、Econazole：皮膚念珠菌、[[皮膚科#皮癬菌感染（Dermatophytosis / Tinea）|皮癬菌]]、陰道念珠菌（陰道錠）、口腔念珠菌（含錠）。
- **Ketoconazole**：
    - 外用：**[[皮膚科#汗斑（Pityriasis Versicolor / Tinea Versicolor）|汗斑]]**、脂漏性皮膚炎（洗髮精）。
    - 口服：**肝毒性**大 → 已不作抗黴菌用；抑制類固醇合成（**男性女乳症**、腎上腺功能不足）→ 曾用於 **Cushing 症候群**。

## Echinocandins

- 機轉：抑制 **β-(1,3)-D-glucan synthase** → 細胞壁合成受阻 → 對 Candida **殺菌**、對 Aspergillus 抑菌。
- 藥物：**Cancidas（Caspofungin）**、**Mycamine（Micafungin）**、Anidulafungin；**IV only**。
- 適應症：
    - **侵襲性念珠菌感染、念珠菌血症首選**（IDSA 2016），尤其**重症、曾用過 azole、C. glabrata、C. auris**。
    - 食道念珠菌感染（無法口服時）。
    - 侵襲性麴菌症**救援**或合併 Voriconazole。
    - Micafungin：骨髓移植前期**預防**。
- 限制：
    - **不進 CSF、尿液、眼睛** → **不能治腦膜炎、念珠菌 UTI、眼內炎**。
    - **對 Cryptococcus、Mucor 無效**。
    - C. parapsilosis 的 MIC 較高（臨床仍多有效）。
- 副作用**最少**：輸注時 histamine 釋放（潮紅）、肝功能異常；交互作用少。
    - Caspofungin：中度肝功能不全減量；與 Cyclosporine 併用肝指數上升。
- 新藥：**Rezafungin** 每週一次 IV（FDA 2023）。
- 同機轉的口服藥：**Ibrexafungerp**（triterpenoid）→ 陰道念珠菌感染。

### 念珠菌血症處置（Candidemia Management）

- **血液培養長出念珠菌一定要治療**（不是汙染）。
- **Echinocandin** 起始 → 病況穩定、菌株敏感、血液培養轉陰 → **5–7 天**後降階為 **Fluconazole**。
- **移除中心靜脈導管**。
- **眼科檢查**（散瞳眼底）：排除**念珠菌眼內炎**（有眼內炎 → 改 Fluconazole 或 AmB，Echinocandin 進不了眼睛）。
- **每天或隔天抽血液培養**直到轉陰。
- 療程：**第一套陰性血液培養後 14 天**（無轉移性感染時）。
- 持續菌血症 → 找轉移病灶（心內膜炎、血栓性靜脈炎、膿瘍）。
- 詳見[[感染科#Candida|Candida]]

## Flucytosine

- 機轉：經黴菌 **cytosine deaminase** 轉成 **5-FU** → 抑制 thymidylate synthase、摻入 RNA。
- **一定合併使用**：單用很快產生抗藥性。
- 適應症：**隱球菌腦膜炎**（+ AmB）；部分念珠菌感染（眼內炎、心內膜炎、尿路）。
- 副作用：**骨髓抑制**（劑量相關）、肝毒性、腸胃不適。
    - **經腎排除** → 腎功能差（例如 AmB 造成的腎毒性）時蓄積 → 依腎功能調整、**TDM**。

## Lamisil（Terbinafine）

- 機轉：抑制 **squalene epoxidase** → ergosterol 減少、squalene 堆積 → 對皮癬菌**殺菌**。
- 親脂、**蓄積在角質、指甲**。
- 適應症：
    - **[[感染科#Dermatophytosis（Tinea）|甲癬]]首選**：250 mg qd，**手指甲 6 週、腳趾甲 12 週**。
    - 頭癬（Trichophyton）、外用治療體癬、足癬。
- 副作用：
    - **肝毒性**（少見但嚴重）→ 用藥前驗肝功能；肝病者避免。
    - **味覺、嗅覺喪失**（可能持續數月）。
    - SJS/TEN、藥物性狼瘡、憂鬱。
    - **CYP2D6 抑制** → β-blocker、三環抗憂鬱劑、Codeine 交互作用。

## Griseofulvin

- 機轉：干擾黴菌**微小管** → 抑制有絲分裂；沉積在新生的角質。
- 適應症：**兒童頭癬**（尤其 **Microsporum**），療程 6–8 週以上；隨**高脂食物**服用增加吸收。
- 副作用：
    - **致畸** → 懷孕禁用；男性停藥後 6 個月內避免使女性懷孕。
    - **CYP 誘導** → 口服避孕藥、Warfarin 效果下降。
    - 光敏感、頭痛、**紫質症惡化**、類 disulfiram 反應。
