## 抗結核藥物總論

### 治療原則（Principles）

- 結核菌**生長很慢**、會進入**休眠**、細胞壁富含 **mycolic acid** → 需要**多藥合併、長療程**。
- **一定合併用藥**：單一藥物 → 自發突變菌被篩選出來 → **抗藥**。
    - 治療失敗時**不可只加一種新藥**（等於單用）。
- 三種菌群，各有主力藥物：
    - **快速分裂的細胞外菌**（空洞內）：**INH** 殺菌最快 → 降低傳染力。
    - **間歇代謝的菌**：**Rifampin** → 預防復發的關鍵。
    - **酸性環境、細胞內半休眠菌**：**PZA** → 讓療程縮短到 6 個月。
- **都治（DOTS）**：關懷員親眼看病人服藥 → 避免不規則服藥產生抗藥性。
- 台灣：**第三類法定傳染病**，確診後 1 週內通報。

### 一線藥物總覽（First-line Drugs）

| 藥物 | 機轉 | 招牌副作用 | 監測 |
|------|------|------------|------|
| **Isoniazid（H）** | 抑制 **mycolic acid** 合成 | **肝炎**、**周邊神經病變** | 肝功能；補 **B6** |
| **Rifampin（R）** | 抑制 **RNA 聚合酶** | 肝炎、**橘紅色體液**、**CYP 誘導** | 肝功能、併用藥物 |
| **Pyrazinamide（Z）** | 酸性環境殺菌 | **肝毒性最強**、**高尿酸** | 肝功能、尿酸 |
| **Ethambutol（E）** | 抑制 **arabinogalactan** 合成 | **視神經炎**（紅綠色盲） | **視力、辨色力** |

- 口訣：**R**ed-orange、**I**njury to liver/neuropathy、**P**urine（尿酸）、**E**yes。
- 依體重給藥、**每天一次空腹**服用（提高 Rifampin 吸收）。
- 台灣常用複方（減少藥量、避免病人只吃其中幾種）：
    - **Rifinah**：Rifampin + INH。
    - **Rifater**：Rifampin + INH + PZA。

## 活動性結核治療（Active TB Regimens）

### 標準處方

- **2HRZE / 4HR**：
    - **強化期 2 個月**：INH + Rifampin + PZA + Ethambutol。
    - **持續期 4 個月**：INH + Rifampin。
    - 藥敏確認對 INH、Rifampin 都敏感 → 可**提早停 Ethambutol**。
- **延長療程**：
    - **空洞** + **2 個月時痰培養仍陽性** → 持續期延長為 **7 個月**（總共 9 個月）。
    - [[神經內科#結核性腦膜炎|結核性腦膜炎]]：總共 **12 個月** + **Dexamethasone**。
    - 骨關節結核：6–9 個月以上。
- **4 個月短程處方**（CDC 2022）：**Rifapentine + Moxifloxacin** + INH + PZA，≥ 12 歲、藥物敏感的肺結核。
- 詳見[[胸腔內科#肺結核（Pulmonary Tuberculosis）|胸腔內科的肺結核]]

### 治療監測（Monitoring）

- **痰液**：每月驗 AFB 抹片與培養，直到**連續 2 次培養陰性**；**第 2 個月**的培養結果決定是否延長療程。
- **肝功能**：治療前抽基礎值；高風險者（肝病、酗酒、HIV、老人、孕婦）定期追蹤；有症狀隨時驗。
- **視力**：Ethambutol 治療前與**每月**檢查視力、辨色力（Ishihara）。
- **尿酸**：PZA 使用中有關節痛時驗。
- 治療 2–3 個月仍培養陽性 → 懷疑**抗藥、服藥不規則、吸收不良** → 驗藥敏。

### 特殊族群（Special Populations）

- **懷孕**：HRE 安全；PZA 美國傾向避免、WHO 認為可用；**避免 Streptomycin**（胎兒耳聾）；補 B6。
- **[[感染科#HIV / AIDS|HIV]]**：
    - 抗結核治療開始後 **2 週內**開始 ART（CD4 < 50 者更要盡早）；**結核性腦膜炎延後** 4–8 週（避免顱內 IRIS）。
    - 併用 protease inhibitor → Rifampin 改 **Rifabutin**；Dolutegravir 改 bid。
    - **IRIS**：ART 後免疫恢復 → 原有結核病灶發炎惡化（發燒、淋巴結腫大）→ 繼續治療，嚴重時給類固醇。
- **腎衰竭**：PZA、Ethambutol 經腎排除 → 改成**每週三次**、**透析後**給藥；INH、Rifampin 不需調整。
- **肝病**：減少肝毒性藥物（例如不用 PZA，延長總療程到 9 個月）。

### 抗結核藥物引起的肝炎（Drug-induced Hepatitis）

- 最常見需要停藥的副作用；肝毒性 **PZA > INH > Rifampin**。
- 危險因子：**老人**、酗酒、B/C 型肝炎、HIV、營養不良、**NAT2 慢乙醯化**。
- **停藥標準**：
    - **ALT > 3 倍上限且有症狀**（噁心、嘔吐、腹痛、黃疸）。
    - **ALT > 5 倍上限**（無症狀也停）。
    - 膽紅素明顯上升。
- 處理：
    - **停所有肝毒性藥物**；排除病毒性肝炎、膽道疾病、酒精。
    - 結核嚴重、不能停藥 → 暫用**非肝毒性藥物**（Ethambutol + Fluoroquinolone ± Amikacin）。
    - ALT < 2 倍上限後**逐一加回**：**Rifampin → INH → PZA**（每 3–7 天加一種並驗肝功能）。
    - 加回某藥後又升高 → 該藥永久停用，依剩下的藥調整處方與療程。
- 詳見[[消化內科#藥物性肝損傷（Drug-Induced Liver Injury, DILI）|藥物性肝損傷]]

## Isoniazid（INH）

### 機轉與藥動（Mechanism & PK）

- **前驅藥**：被結核菌的 **KatG**（catalase-peroxidase）活化 → 抑制 **InhA** → **mycolic acid 無法合成**。
- 對快速分裂菌**殺菌**、對休眠菌抑菌。
- 抗藥：
    - **katG 突變**：高度抗藥。
    - **inhA 突變**：低度抗藥，與 **Ethionamide 交叉抗藥**。
- 肝臟經 **NAT2 乙醯化**代謝：
    - **慢乙醯化**：血中濃度高 → **神經病變、肝毒性**較多。
    - 快乙醯化：濃度低；東亞人快乙醯化者比例較高。
- 適應症：活動性結核、潛伏結核（**9H、6H**，或合併 Rifapentine、Rifampin 的短程處方）。

### 副作用（Adverse Effects）

- **肝炎**：年齡越大風險越高；併用 Rifampin 時增加。
- **周邊神經病變**：INH 增加 **pyridoxine（B6）** 排除。
    - **補 B6**：懷孕、哺乳、糖尿病、酗酒、營養不良、HIV、腎衰竭。
- **藥物性狼瘡**：**抗組織蛋白抗體（anti-histone）** 陽性。
- **[[血液腫瘤科#Sideroblastic Anemia|鐵芽球性貧血]]**：ALA synthase 需要 B6。
- **過量 → 難治性癲癇**（GABA 合成不足）+ 代謝性酸中毒 → **IV Pyridoxine**（每吃 1 g INH 給 1 g，最多 5 g）。
- **CYP 抑制**：Phenytoin、Carbamazepine 濃度上升。
- 食用含 histamine、tyramine 的魚類、起司 → 潮紅、心悸（少見）。

## Rifampin

- 機轉、適應症、副作用與交互作用見[[抗生素：抑制 mRNA 合成#Rifampin|Rifampin]]。
- 結核治療中最重要的**滅菌**藥物；**Rifampin 抗藥 ≈ MDR-TB 的指標**（Xpert MTB/RIF）。
- 結核相關重點：
    - **強效 CYP 誘導** → 口服避孕藥、Warfarin、HIV 藥物、抗排斥藥、類固醇失效。
    - HIV 併用 PI → 改 **Rifabutin**。
    - 潛伏結核：**4R**、**3HR**；Rifapentine 用於 **3HP**、**1HP**。

## Pyrazinamide（PZA）

- **前驅藥**：被 **pyrazinamidase**（*pncA*）轉成 pyrazinoic acid → 在**酸性環境**（巨噬細胞吞噬體、乾酪樣壞死）殺菌。
    - 只用在強化期 2 個月，但能把總療程從 9 個月**縮短到 6 個月**。
- **M. bovis 天生抗藥**（缺 pncA 活性）。
- 副作用：
    - **肝毒性**：抗結核藥中**最強**，且劑量相關。
    - **高尿酸血症**：抑制腎小管排泄尿酸 → 多無症狀，少數[[骨科#痛風性關節炎（Gout）|痛風]]發作。
    - **關節痛**（非痛風性）→ NSAID 處理，不一定要停藥。
    - 皮疹、光敏感、腸胃不適。

## Ethambutol（EMB）

- 抑制 **arabinosyl transferase**（*embB*）→ arabinogalactan 合成受阻；**抑菌**。
- 角色：**防止其他藥物產生抗藥**；藥敏確認敏感後可停。
- 副作用：
    - **[[眼科#視神經炎（Optic Neuritis）|視神經炎]]**：**視力下降、紅綠色盲**、中心盲點。
        - **劑量相關**（> 15 mg/kg/day、**腎功能差**時蓄積）。
        - **每月**檢查視力、辨色力；異常 → **立即停藥**，多數可恢復。
        - 幼兒無法表達視力變化 → 小心使用。
    - 周邊神經病變、輕度高尿酸。
- 經腎排除 → 腎衰竭時每週三次、透析後給。

## 多重抗藥性結核（MDR-TB）

### 定義（WHO 2021）

| 名稱 | 抗藥 |
|------|------|
| **RR-TB** | Rifampin 抗藥 |
| **MDR-TB** | **INH + Rifampin** |
| **pre-XDR-TB** | MDR + **Fluoroquinolone** |
| **XDR-TB** | pre-XDR + **Bedaquiline 或 Linezolid** 至少一種 |

- 危險因子：**曾經治療過**（尤其不規則服藥、中斷）、接觸 MDR-TB 病人、來自高盛行地區。
- 診斷：**Xpert MTB/RIF** 快速偵測 Rifampin 抗藥 → 再做完整藥敏。

### 治療（Treatment）

- **BPaLM 6 個月**（WHO 2022）：**B**edaquiline + **P**retomanid + **L**inezolid + **M**oxifloxacin，≥ 14 歲。
    - **pre-XDR**（FQ 抗藥）→ 去掉 Moxifloxacin（**BPaL**）。
- 無法使用 BPaLM → 依藥敏組合 WHO 分組藥物，療程 9–20 個月。
- 台灣：**MDR-TB 醫療照護體系**（2007 年起）→ 由專責團隊治療、**都治 plus**、治療費用由疾管署支付。

### 二線藥物（Second-line Drugs）

| WHO 分組 | 藥物 | 重點副作用 |
|----------|------|------------|
| **A**（優先全用） | **Levofloxacin/Moxifloxacin** | QT 延長、肌腱 |
| | **Bedaquiline**（抑制 **ATP synthase**） | **QT 延長**、肝毒性 |
| | **Linezolid** | **骨髓抑制**、周邊與視神經病變 |
| **B**（加入） | **Clofazimine** | **皮膚粉紅至棕黑色素沉著**、QT 延長 |
| | **Cycloserine** | **精神症狀**（憂鬱、精神病）、**癲癇** |
| **C**（補足處方） | Delamanid、Pretomanid（硝基咪唑類） | QT 延長 |
| | Amikacin（Streptomycin） | **耳毒性**、腎毒性 |
| | Ethionamide | 腸胃不適、**甲狀腺低下** |
| | Para-aminosalicylic acid | 腸胃不適、**甲狀腺低下** |
| | Carbapenem + Clavulanate、Ethambutol、PZA | |

- **QT 延長藥物**常同時使用（Bedaquiline、Clofazimine、Moxifloxacin、Delamanid）→ 定期心電圖、矯正電解質。

## 其他分枝桿菌（Other Mycobacteria）

- **[[感染科#Nontuberculous Mycobacteria（NTM）|NTM]]**：
    - **MAC 肺病**：**Azithromycin + Ethambutol + Rifampin**，培養陰轉後再治療 **12 個月**；難治 → 加吸入式 liposomal **Amikacin**。
    - **M. abscessus**：多藥合併（Amikacin、Imipenem、Tigecycline、Macrolide）；常有誘導型 Macrolide 抗藥（*erm(41)*）。
- **[[感染科#Mycobacterium leprae（漢生病/麻風）|漢生病]]**（WHO 2018）：**Rifampin + Dapsone + Clofazimine**，少菌型 6 個月、多菌型 12 個月。
