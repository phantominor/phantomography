## 醣胜肽類總論（Glycopeptides）

### 機轉與涵蓋範圍（Mechanism & Spectrum）

- 機轉：結合細胞壁前驅物末端的 **D-Ala-D-Ala** → 阻斷 transglycosylation 與 transpeptidation → 細胞壁無法合成。
    - 與 β-lactam 不同：β-lactam 結合 PBP（酵素），醣胜肽類結合**受質**。
- 對 Staphylococcus **殺菌（慢）**，對 Enterococcus **抑菌**。
- **只涵蓋革蘭氏陽性菌**：分子太大 → 穿不過 GNR 外膜。
    - **MRSA**、CoNS（MRSE）、Enterococcus（非 VRE）、PRSP、**C. difficile**（口服）、Corynebacterium、Bacillus。
- **口服不吸收** → 口服只用於 **C. difficile 腸炎**。

### 抗藥性（Resistance）

| 抗藥菌 | 機轉 | 重點 |
|--------|------|------|
| **VRE（vanA）** | D-Ala-D-Ala → **D-Ala-D-Lac** | 高度抗 Vancomycin **與 Teicoplanin**；E. faecium 為主 |
| VRE（vanB） | D-Ala-D-Lac | 抗 Vancomycin，**Teicoplanin 仍有效** |
| vanC | D-Ala-D-Ser | E. gallinarum、E. casseliflavus **天生低度抗藥** |
| **VISA** | **細胞壁增厚** → 藥物被困在外層 | Vancomycin MIC **:red[4–8]** μg/mL |
| VRSA | 取得 vanA 基因 | MIC **≥ 16**；極少見 |

- MRSA 的 Vancomycin MIC ≥ 2 或治療失敗 → 考慮換 **Daptomycin**。
- VRE 治療：**Linezolid** 或 **Daptomycin**（見[[感染科#Enterococcus|Enterococcus]]）。

### 各藥比較（Comparison）

| | Vancomycin | Teicoplanin | Lipoglycopeptides |
|--|------------|-------------|-------------------|
| 半衰期 | 6–8 小時 | **很長（約 3 天）** → 需 loading | Dalbavancin 約 2 週 |
| 給藥 | IV q8–12h；口服（C. difficile） | IV 或 **IM**，qd | 1–2 劑 |
| 腎毒性 | **有** | 較低 | Telavancin 有 |
| Red man | **常見** | 少 | 少 |
| vanB VRE | 無效 | **有效** | Oritavancin 有效 |
| TDM | **AUC 或 trough** | Trough | 不需要 |

## Vancomycin

### 適應症（Indications）

- **MRSA 首選**：菌血症、[[心臟內科#感染性心內膜炎（Infective Endocarditis, IE）|心內膜炎]]、骨髓炎、HAP/VAP、皮膚軟組織感染。
    - MRSA 肺炎：Vancomycin 或 **Linezolid**。
- **經驗治療加上 Vancomycin 的時機**：
    - [[神經內科#細菌性腦膜炎|細菌性腦膜炎]]：**Ceftriaxone + Vancomycin**（PRSP）。
    - [[血液腫瘤科#Febrile Neutropenia|嗜中性球低下發燒]]：**不常規加**；有導管感染、皮膚軟組織感染、肺炎、血行動力不穩定才加。
    - 有 MRSA 危險因子的 HAP/VAP、敗血症。
- **CoNS 人工植入物感染**（人工瓣膜、人工關節、VP shunt）：Vancomycin ± **Rifampin**（穿透 biofilm）。
- [[外科概論#預防性抗生素|手術預防]]：**MRSA 帶菌**或 **β-lactam 過敏** → **:red[切皮前 120 分鐘內]**開始滴。
- Ampicillin 抗藥、非 VRE 的 Enterococcus。
- **[[感染科#C. difficile（Pseudomembranous colitis，偽膜性大腸炎）|C. difficile]]**：**口服** 125 mg qid × 10 天。
    - IDSA 2021：初次感染首選 **Fidaxomicin**，口服 Vancomycin 為替代。
    - **猛爆性（fulminant）**：口服 Vancomycin **500 mg qid** + **IV Metronidazole**；腸阻塞 → 加 Vancomycin 灌腸。
    - **IV Vancomycin 對 C. difficile 無效**（不會分泌到腸腔）。
- **不用於 MSSA**：療效比 Oxacillin、Cefazolin 差 → 確認 MSSA 就換 β-lactam。

### 用法與藥物監測（Dosing & TDM）

- 依體重給藥：15–20 mg/kg q8–12h；重症 → **loading 20–35 mg/kg**（最多 3 g）。
- **經腎排除** → 依腎功能調整；血液透析病人依血中濃度補打。
- **TDM**（ASHP/IDSA 2020）：
    - 目標 **:red[AUC/MIC 400–600]**（假設 MIC = 1）。
    - 舊目標 **trough 15–20 μg/mL** 不再建議 → 腎毒性較多、療效沒有較好。
    - 抽兩點（滴完 1–2 小時、下一劑前）用軟體估算 AUC；沒有軟體的醫院仍常用 trough。

### 副作用（Adverse Effects）

- **Vancomycin infusion reaction**（Red man syndrome）：見[[#Vancomycin Infusion Reaction（Red Man Syndrome）|下方]]。
- **腎毒性**：
    - 危險因子：**高 trough**、長療程、合併 **Aminoglycoside**、**Tazocin**、顯影劑、Furosemide。
- **耳毒性**：少見；合併 Aminoglycoside 時風險↑。
- 血球：**嗜中性球低下**（> 1–2 週）、**免疫性血小板低下**。
- 皮膚：**[[皮膚科#Drug Reaction with Eosinophilia and Systemic Symptoms（DRESS）|DRESS]]**（Vancomycin 是常見原因）、**linear IgA bullous dermatosis**（藥物引起者最常見是 Vancomycin）。
- 靜脈炎 → 長期使用走中心靜脈導管。

### Vancomycin Infusion Reaction（Red Man Syndrome）

- 機轉：直接刺激 **mast cell 釋放 histamine** → **非 IgE、不是過敏**。
- 表現：滴注中或滴完不久 → **臉、頸、上半身潮紅**、搔癢；嚴重時低血壓、胸痛。
- 與**滴注速度**有關：**滴太快**、劑量大。
- 處理：**暫停 → 症狀緩解後放慢速度重新滴**、給 **antihistamine**。
    - 預防：每 1 g 滴 **至少 1 小時**、預先給 antihistamine。
- **之後可以繼續使用**，不需標記為過敏。
- 其他藥物也可能（Ciprofloxacin、Amphotericin B、Rifampin），但 Vancomycin 最典型。
- 與藥物過敏的鑑別見[[皮膚系統主訴#藥物疹與嚴重皮膚反應（Drug Eruptions / SCAR）|藥物疹]]。

## Teicoplanin

- 醣胜肽類；機轉、涵蓋與 Vancomycin 相近。
- **半衰期很長** → 需 **loading**：6–12 mg/kg q12h × 3 劑 → 6–12 mg/kg qd。
    - 骨關節感染、心內膜炎用高劑量（12 mg/kg）。
- 可 **IM**、每天一次 → 適合門診或長期治療（骨髓炎）。
- 優點：**腎毒性、Red man 較少**；**vanB VRE 有效**。
- 缺點：**CNS 穿透差**、高度蛋白結合；美國未核准（歐洲、亞洲使用）。
- TDM：trough（重症、骨關節、心內膜炎目標較高）。

## Lipoglycopeptides（脂醣胜肽類）

- 醣胜肽 + **脂肪側鏈** → 錨定在細胞膜 → **加上破壞細胞膜**的作用 → 殺菌較快。
- 適應症：急性細菌性皮膚軟組織感染（ABSSSI）。

| 藥物 | 特點 |
|------|------|
| **Telavancin** | qd；**腎毒性**、**QT 延長**、味覺異常；動物致畸 → 育齡女性先驗孕 |
| **Dalbavancin** | **半衰期約 2 週** → **1–2 劑**完成療程 |
| **Oritavancin** | **單劑**；**干擾凝血檢驗（假性延長 PT/aPTT）**；vanA VRE 部分有效 |

## 其他細胞壁合成抑制劑（Other Cell Wall Synthesis Inhibitors）

### Bacitracin

- 機轉：抑制 **bactoprenol（undecaprenyl pyrophosphate）去磷酸化** → 細胞壁前驅物無法運出細胞膜。
- 涵蓋：革蘭氏陽性菌。
- **全身使用有腎毒性 → 只做外用**（軟膏）。
- 微生物鑑定：**GAS（S. pyogenes）對 bacitracin 敏感**、GBS 有抗性 → 區分 β 溶血鏈球菌。

### Fosfomycin

- 機轉：**phosphoenolpyruvate 類似物** → 抑制 **MurA** → 阻斷細胞壁合成的**第一步**。
- 與其他抗生素**沒有交叉抗藥**。
- **口服**（fosfomycin tromethamine）：**單純膀胱炎**，**:red[3 g 單次]**。
    - 對 **ESBL E. coli** 多數仍有效 → 社區 ESBL 膀胱炎的口服選擇。
    - **不用於腎盂腎炎**（組織濃度不足）。
- **靜脈**：多重抗藥菌（CRE、MRSA）的**合併治療**；單用易產生抗藥性。
    - 副作用：**鈉負荷大 → 高血鈉**、**低血鉀**。
