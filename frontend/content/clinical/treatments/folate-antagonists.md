## 葉酸拮抗劑總論（Folate Antagonists）

### 機轉（Mechanism）

- 細菌要**自己合成葉酸**；人類從飲食攝取 → 選擇性作用在細菌。
- 合成路徑：PABA →（**dihydropteroate synthase**）→ dihydrofolate →（**DHFR**）→ tetrahydrofolate → 合成 purine、thymidine。
- **Sulfonamides、Dapsone**：PABA 類似物 → 抑制 **dihydropteroate synthase**。
- **Trimethoprim、Pyrimethamine**：抑制 **DHFR**。
- **TMP-SMX 連續阻斷（sequential blockade）**：單用各自**抑菌**，合用**協同殺菌**。

| DHFR 抑制劑 | 作用對象 | 用途 |
|-------------|----------|------|
| **Trimethoprim** | 細菌 | TMP-SMX |
| **Pyrimethamine** | 原蟲 | 弓形蟲、瘧疾 |
| **Methotrexate** | 人類 | 化療、類風濕性關節炎 |

### 共同副作用（Class Effects）

- **葉酸缺乏 → 巨球性貧血**、全血球低下：高劑量、長療程、合併 Methotrexate 時。
    - 補 **leucovorin（folinic acid）**：已經是還原型，繞過 DHFR。
    - **不補 folic acid**：還要經過 DHFR，被藥物擋住；也可能降低抗原蟲效果。
- **[[血液腫瘤科#G6PD 缺乏症（Glucose-6-Phosphate Dehydrogenase Deficiency）|G6PD 缺乏]] → 溶血**：Sulfonamides、**Dapsone** 都會。
- 懷孕第一孕期：葉酸拮抗 → 神經管缺陷風險。

## Baktar（TMP-SMX）

### 涵蓋範圍（Spectrum）

- 比例固定 **TMP : SMX = 1 : 5**；SS 錠 80/400 mg、DS 錠 160/800 mg。
- 口服**吸收接近 100%** → 口服與 IV 效果相同；組織穿透好（含 CNS、前列腺）。
- 涵蓋：
    - 革蘭氏陽性：**S. aureus（含社區型 MRSA）**、Listeria、**Nocardia**。
    - 革蘭氏陰性：E. coli、Klebsiella、Proteus、**Stenotrophomonas**、**Burkholderia**。
    - 非細菌：**PJP**、**Toxoplasma**、Cystoisospora、Cyclospora。
- **沒有涵蓋**：**Pseudomonas aeruginosa**、厭氧菌、**Enterococcus**（體內能利用外來葉酸）、Mycoplasma。

### 適應症（Indications）

- **[[感染科#Pneumocystis jirovecii（PJP）|PJP]]**：
    - 治療首選：TMP **15–20 mg/kg/day** 分 q6–8h × **21 天**；PaO₂ < 70 mmHg 合併**類固醇**。
    - 預防：HIV **CD4 < 200**、長期類固醇、器官移植、化療 → DS 或 SS 每天一顆。
- **[[感染科#Toxoplasma gondii|弓形蟲]]預防**：HIV **CD4 < 100** 且 IgG 陽性 → DS qd（同時預防 PJP）。
- **泌尿道感染**：[[泌尿科#泌尿道感染（UTI）|單純膀胱炎]] DS bid × **3 天**（當地抗藥率 < 20% 才用）；前列腺炎 4–6 週。
- **皮膚軟組織感染**：社區型 MRSA 膿瘍引流後的口服選擇。
    - 對 **GAS 較弱** → 蜂窩組織炎經驗治療要加 β-lactam。
- **Stenotrophomonas maltophilia 首選**：天生對 Carbapenem 抗藥。
- **[[感染科#Nocardia vs Actinomyces|Nocardia]]**：首選，療程數月；腦部感染合併其他藥。
- **[[感染科#其他重要病原|類鼻疽（Melioidosis）]]**：台灣南部颱風季常見；IV Meropenem 或 Ceftazidime 後，口服 TMP-SMX **3–6 個月**清除。
- [[感染科#Listeria monocytogenes|Listeria]]：Penicillin 過敏時的替代。
- 其他：Cystoisospora、Cyclospora 腹瀉、Whipple disease 維持治療。

### 副作用（Adverse Effects）

- **高血鉀**：Trimethoprim 結構像 **Amiloride** → 阻斷集尿管 **ENaC**。
    - 高劑量、腎功能差、合併 **ACEI/ARB、Spironolactone** → 定期驗 K⁺。
    - 詳見[[電解質與酸鹼#高血鉀（Hyperkalemia）|高血鉀]]。
- **Creatinine 假性上升**：Trimethoprim 抑制腎小管**分泌 creatinine** → GFR 沒有真的下降。
    - 但也可能造成真正的 AKI（間質性腎炎、結晶尿）→ 搭配 BUN、尿液判斷。
- **皮膚**：皮疹常見；**[[皮膚科#Stevens-Johnson Syndrome（SJS）/ Toxic Epidermal Necrolysis（TEN）|SJS/TEN]]**、DRESS → Sulfonamides 是 SJS/TEN 常見原因。
    - **HIV 病人過敏率高（約 50%）**；輕度皮疹可在嚴密觀察下繼續或做**減敏**。
- **血液**：骨髓抑制、血小板低下、G6PD 缺乏者溶血。
- 新生兒 **[[小兒科#核黃疸（Kernicterus）|核黃疸]]**：Sulfonamides 與 bilirubin **競爭白蛋白結合** → 懷孕末期、**< 2 個月嬰兒**避免。
- 其他：肝炎、無菌性腦膜炎、低血鈉、低血糖（腎功能差時）。

### 交互作用（Interactions）

- **Warfarin**：抑制 CYP2C9 → **INR 上升、出血** → 減量或密集追蹤 INR。
- **Methotrexate**：雙重 DHFR 抑制 + 減少腎排除 → **全血球低下**，避免合用。
- **ACEI/ARB、Spironolactone**：高血鉀。
- Phenytoin、Sulfonylurea：濃度上升（低血糖）。

### 抗藥性（Resistance）

- 質體帶的 **sul1、sul2**（耐藥的 dihydropteroate synthase）與 **dfr**（耐藥的 DHFR）。
- 細菌大量製造 PABA。
- 台灣社區 E. coli 抗藥率高 → 泌尿道感染經驗治療要參考當地抗藥率。

## 其他 Sulfonamides

- **Sulfadiazine**：+ **Pyrimethamine** + leucovorin → **弓形蟲腦炎**首選。
    - 尿中溶解度低 → **結晶尿**、腎結石 → 多喝水、鹼化尿液。
- **Silver sulfadiazine**：燒燙傷外用，涵蓋 Pseudomonas；可能短暫白血球低下。
- **Sulfasalazine**：Sulfapyridine + 5-ASA，用於潰瘍性結腸炎、類風濕性關節炎（不當抗生素用）。
- **Sulfa 過敏的交叉反應**：
    - 抗生素類 sulfonamide 的過敏來自 **N4 arylamine** 與 N1 環狀結構。
    - 非抗生素類（**Furosemide、Thiazide**、Sulfonylurea、Celecoxib）沒有這些結構 → 交叉反應**很低**，不需要一律避免。

## Dapsone

- 機轉：PABA 類似物 → 抑制 dihydropteroate synthase；另有抗發炎作用（抑制嗜中性球）。
- 適應症：
    - **[[感染科#Mycobacterium leprae（漢生病/麻風）|漢生病]]**：多藥合併治療的一員。
    - **PJP 預防**：TMP-SMX 過敏時的替代（加 Pyrimethamine 可同時預防弓形蟲）。
    - 皮膚：**疱疹樣皮膚炎（dermatitis herpetiformis）**、嗜中性球皮膚病。
- 副作用：
    - **溶血**：**用藥前驗 G6PD**；G6PD 正常也會輕度溶血。
    - **變性血紅素血症（methemoglobinemia）**：發紺、血氧機讀值約 85% 不隨給氧改善 → **Methylene blue**。
    - **Dapsone 過敏症候群**：類似 DRESS；與 **HLA-B\*13:01** 相關，華人帶因率高。
    - 顆粒性白血球缺乏（agranulocytosis）。

## Pyrimethamine

- 機轉：抑制**原蟲 DHFR**。
- 適應症：**弓形蟲腦炎**（+ Sulfadiazine 或 Clindamycin）、先天性弓形蟲感染。
- **一定要合併 leucovorin**：避免骨髓抑制。
- 瘧疾：Sulfadoxine-pyrimethamine 因抗藥性已少用，現多用於孕婦間歇預防治療（流行區）。
