## 細胞膜作用藥物總論（Membrane-active Agents）

- 共同點：直接破壞細胞膜 → **濃度依賴型殺菌**，殺菌快。
- 兩者涵蓋**剛好互補**：Daptomycin 只打革蘭氏陽性菌、Polymyxin 只打革蘭氏陰性菌。
- 臨床定位都是**抗藥菌的後線用藥**：Daptomycin 用於 MRSA、VRE；Polymyxin 用於 CRAB、CRE。

| | Daptomycin | Polymyxin B / Colistin |
|--|------------|------------------------|
| 構造 | 環狀脂胜肽（cyclic lipopeptide） | 陽離子多胜肽（cationic polypeptide） |
| 作用位置 | 革蘭氏陽性菌**細胞膜** | 革蘭氏陰性菌**外膜 LPS**（lipid A） |
| 涵蓋 | **MRSA、VRE** | **CRAB**、CRPA、CRE |
| 給藥 | IV qd | IV q12h；Colistin 可吸入 |
| 主要副作用 | **CK 上升、肌病變**、嗜酸性球肺炎 | **腎毒性**、**神經毒性** |
| 不能用 | **肺炎** | Proteus、Serratia 等天生抗藥菌 |

## Daptomycin

### 機轉與涵蓋範圍（Mechanism & Spectrum）

- 機轉：**依賴鈣離子**插入革蘭氏陽性菌細胞膜 → 形成通道 → **K⁺ 外流、細胞膜去極化** → 快速殺菌。
    - 不造成菌體溶解 → 理論上內毒素、毒素釋放較少。
- **只涵蓋革蘭氏陽性菌**：穿不過 GNR 外膜。
    - **MRSA**、VISA、VRSA、CoNS、**VRE**（E. faecium、E. faecalis）、Streptococcus。
- 濃度依賴型、有 PAE → **一天一次**。

### 適應症（Indications）

- **複雜性皮膚軟組織感染**：4 mg/kg qd。
- **[[感染科#Staphylococcus aureus|S. aureus 菌血症]]**、**右側心內膜炎**：6 mg/kg qd。
    - 實務上常用**高劑量 8–12 mg/kg**：持續菌血症、左側心內膜炎、VRE。
- **MRSA 救援治療**：Vancomycin 失敗、MIC ≥ 2 → 換 **高劑量 Daptomycin ± β-lactam**。
    - 合併 Ceftaroline 或 Oxacillin：β-lactam 讓細胞膜更容易被 Daptomycin 結合（**seesaw effect**）。
- **[[感染科#Enterococcus|VRE]] 菌血症**：Daptomycin 或 **Linezolid**；用高劑量，常合併 β-lactam。
- [[骨科#急性骨髓炎（Acute Osteomyelitis）|骨髓炎]]、[[骨科#人工關節感染（Periprosthetic Joint Infection, PJI）|人工關節感染]]：Vancomycin 無法使用時的替代。
- **:red[不能用於肺炎]**：被**肺泡表面張力素（surfactant）不活化**。
    - 例外：右側心內膜炎造成的**敗血性肺栓塞**是經血行感染 → 仍有效。

### 用法（Dosing）

- 依實際體重給藥，IV **qd**。
- **經腎排除**：CrCl < 30 → **q48h**（或同劑量延長間隔）；血液透析後給。
- 曾用 Vancomycin 的 MRSA → Daptomycin MIC 可能**一起上升**（細胞壁增厚，與 VISA 機轉重疊）→ 換藥前先驗 MIC。

### 副作用（Adverse Effects）

- **肌病變（CK 上升）**：劑量相關；嚴重時橫紋肌溶解。
    - **每週驗 CK**；同時用 **statin** → 暫停 statin 或更密集監測。
    - 停藥標準：CK **> 5 倍上限且有肌肉症狀**，或 **> 10 倍上限**（無症狀也停）。
- **[[胸腔內科#嗜酸性球性肺炎（Eosinophilic Pneumonia）|嗜酸性球肺炎]]**：用藥 2–4 週後發燒、呼吸困難、肺浸潤 → 停藥、類固醇。
- 部分試劑會**假性延長 PT/INR** → 下一劑前抽血可避免。
- 周邊神經病變（少見）。

## Polymyxins（多黏菌素類）

### 機轉與涵蓋範圍（Mechanism & Spectrum）

- 兩種：**Polymyxin B** 與 **Polymyxin E（Colistin）**，構造只差一個胺基酸。
- 機轉：陽離子結合 **LPS 的 lipid A** → 置換穩定外膜的 **Ca²⁺、Mg²⁺** → 破壞外膜與內膜（類似**清潔劑**）→ 殺菌。
    - 同時中和內毒素 → Polymyxin B 吸附管柱可做內毒素血液灌流（日本使用；敗血性休克療效未證實）。
- **只涵蓋革蘭氏陰性菌**：
    - **Acinetobacter baumannii**、**Pseudomonas aeruginosa**、Klebsiella、E. coli、Enterobacter。
- **天生抗藥**（LPS 結構不同）：
    - **Proteus**、**Providencia**、**Morganella**、**Serratia**、**Burkholderia**。
    - Neisseria、所有革蘭氏陽性菌、厭氧菌。

### 適應症（Indications）

- 定位：**多重抗藥革蘭氏陰性菌的最後線**；有新藥可選時優先用新藥。
- **[[感染科#Acinetobacter baumannii|CRAB]]**：台灣加護病房常見 → Colistin 或 Polymyxin B 是主要選項之一。
    - 不單用：合併**高劑量 Unasyn**、Tigecycline 或 Carbapenem。
- **CRE**：KPC、OXA-48 優先用 **Ceftazidime-avibactam**；Polymyxin 只在沒有新藥或過敏時使用。
- **[[感染科#Pseudomonas aeruginosa|DTR Pseudomonas]]**：優先新型 β-lactam；Polymyxin 為替代。
- **兩種怎麼選**（2019 國際共識）：
    - **全身感染 → Polymyxin B**：不經腎排除、血中濃度較快達標、腎毒性較低。
    - **下泌尿道感染 → Colistin**：以前驅物形式從尿液排出，在膀胱轉成活性藥物。
- **吸入 Colistin**：[[胸腔內科#院內型 / 呼吸器相關型肺炎（HAP / VAP）|VAP]] 的輔助治療（合併 IV）。
- 外用：Polymyxin B 眼藥、軟膏（合併 Neomycin、Bacitracin）。
- 口服 Colistin 不吸收 → 用於腸道去汙染（SDD）。

### 用法（Dosing）

- **Colistin**：給的是無活性前驅物 **colistimethate sodium（CMS）** → 體內慢慢轉成 colistin。
    - 劑量單位混亂：**1 MIU CMS ≈ 33 mg colistin base activity（CBA）** → 開立時確認單位。
    - 轉換慢 → **一定要 loading**：**:red[9 MIU（300 mg CBA）]**，之後依腎功能給維持劑量。
    - 經腎排除 → 依 CrCl 調整。
- **Polymyxin B**：本身就是活性藥物。
    - loading 2–2.5 mg/kg → 1.25–1.5 mg/kg q12h。
    - **不經腎排除** → **不需依腎功能調整**。

### 副作用（Adverse Effects）

- **腎毒性**：急性腎小管壞死，劑量相關；發生率可達 30–60%，多可回復。
    - 避免合併 **Aminoglycoside**、Vancomycin、顯影劑等腎毒性藥物。
    - Colistin 腎毒性 > Polymyxin B。
- **神經毒性**：
    - 口周麻、肢端感覺異常、頭暈、意識改變。
    - **神經肌肉阻斷 → 呼吸衰竭**：合併肌肉鬆弛劑、Aminoglycoside 時風險↑。
- Polymyxin B：**皮膚色素沉著**、輸注相關潮紅。
- 吸入：支氣管痙攣 → 先給支氣管擴張劑。

### 抗藥性（Resistance）

- 共同機轉：**修飾 lipid A**（加上 phosphoethanolamine 或 L-Ara4N）→ 降低正電荷吸引。
- 染色體突變：Klebsiella **mgrB**、pmrAB、phoPQ。
- **mcr-1**：**質體**攜帶 → 可在菌種間水平傳播。
    - 2015 年在中國養豬場首次發現（與畜牧業大量使用 Colistin 有關），之後全球、台灣皆有檢出。
- 治療中可能出現**異質性抗藥（heteroresistance）** → 不單用的原因之一。
