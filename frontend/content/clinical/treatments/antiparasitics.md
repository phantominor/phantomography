## 抗寄生蟲藥物總論

| 對象 | 主要藥物 |
|------|----------|
| **瘧原蟲** | **Artemisinins**、Chloroquine、**Primaquine**、Malarone、Mefloquine、Quinine |
| **腸道與組織原蟲** | **Metronidazole**/Tinidazole、Paromomycin、Nitazoxanide、TMP-SMX、Pyrimethamine |
| **線蟲**（Nematodes） | **Albendazole/Mebendazole**、**Ivermectin**、Pyrantel、DEC |
| **絛蟲**（Cestodes） | **Praziquantel**、Albendazole（囊尾蚴症、包蟲） |
| **吸蟲**（Trematodes） | **Praziquantel**（Fasciola → **Triclabendazole**） |
| **體外寄生蟲** | **Permethrin**、口服 Ivermectin |

- 記憶：**線蟲 → -bendazole、Ivermectin**；**扁蟲（絛蟲、吸蟲）→ Praziquantel**。
- 台灣：瘧疾、多數熱帶寄生蟲病是**境外移入**；部分罕用藥（例如 IV Artesunate）由**疾管署統籌儲備**，需要時向疾管署申請。

## 抗瘧藥（Antimalarials）

### 抗瘧藥總論

- 依瘧原蟲生活史的作用階段：

| 階段 | 藥物 | 用途 |
|------|------|------|
| **紅血球期**（血中裂殖體） | Artemisinins、Chloroquine、Quinine、Mefloquine、Atovaquone | **治療急性症狀** |
| **肝臟期**（**hypnozoite**） | **Primaquine、Tafenoquine** | **根除 P. vivax、P. ovale**，防止復發 |
| 肝臟期（初始） | Atovaquone-proguanil、Primaquine | 預防（causal prophylaxis） |

- **[[感染科#Plasmodium（瘧疾）|瘧疾]]治療原則**：
    - **P. falciparum** 或不確定種類 → 當作**抗藥性**處理（Artemisinin 類）。
    - **嚴重瘧疾**（意識改變、休克、ARDS、腎衰竭、低血糖、**原蟲血症 > 5%**）→ **IV Artesunate**。
    - **P. vivax、P. ovale** → 紅血球期治療後加 **Primaquine**（先驗 **G6PD**）。
- 預防用藥見[[家庭醫學科#瘧疾預防|瘧疾預防]]。

### Artemisinins

- 機轉：**endoperoxide 橋**被原蟲消化血紅素產生的 **heme 鐵**活化 → **自由基** → 殺原蟲；**作用最快**。
- **半衰期很短** → 一定合併長效藥（**ACT，artemisinin-based combination therapy**）→ 防止復發與抗藥。
- **Artemether-lumefantrine**（Coartem）：**無併發症 P. falciparum 首選**之一；**隨含脂肪食物**服用。
- **IV Artesunate**：**嚴重瘧疾首選**（死亡率比 Quinine 低）。
    - **延遲性溶血**：治療後 1–3 週（被藥物「pitting」的紅血球被清除）→ 追蹤血紅素。
- 抗藥：東南亞（湄公河流域）與非洲部分地區出現 **kelch13** 突變 → 清除變慢。

### Chloroquine 與 Hydroxychloroquine

- 機轉：在原蟲食物泡中**阻止 heme 聚合成 hemozoin** → 游離 heme 毒殺原蟲。
- **P. falciparum 幾乎全球抗藥**（*PfCRT* 外排）→ 只用於**仍敏感地區**、P. vivax（部分地區）、P. malariae、P. ovale。
- **Hydroxychloroquine** 主要用於**風濕免疫疾病**（SLE、類風濕性關節炎、Sjögren）。
- 副作用：
    - **視網膜病變**（**bull's eye maculopathy**）：累積劑量相關、不可逆。
        - Hydroxychloroquine **≤ 5 mg/kg/day**（實際體重）；**基礎眼科檢查** → 用藥 **5 年後每年**篩檢（高風險者提早）。
        - **亞洲人**病變常在**黃斑部以外** → 篩檢要涵蓋較大範圍。
    - **QT 延長**、心肌病變（長期）。
    - 皮膚色素沉著、搔癢（非洲裔常見）、乾癬惡化、**G6PD 缺乏溶血**（少）、低血糖。
    - **過量**：心律不整、低血鉀、癲癇 → 致死率高。

### Primaquine 與 Tafenoquine

- 作用於**肝臟 hypnozoite** → **P. vivax、P. ovale 根治**（radical cure）。
- **Primaquine**：14 天；**Tafenoquine**：**單次**（與 Chloroquine 合用）。
- **:red[用藥前一定驗 G6PD]**：缺乏 → **嚴重溶血**、變性血紅素血症。
    - Tafenoquine 半衰期很長 → G6PD 活性需 **> 70%** 才可使用。
- **懷孕禁用**（胎兒 G6PD 狀態未知）→ 改每週 Chloroquine 抑制到產後。

### Malarone（Atovaquone-proguanil）

- **Atovaquone**：抑制粒線體電子傳遞（cytochrome bc1）；**Proguanil**：DHFR 抑制劑（協同）。
- 用途：
    - **預防**：出發前 **1–2 天**、離開疫區後 **7 天**（對肝臟期也有效，所以回國後時間短）。
    - 無併發症瘧疾治療。
- 副作用少（腸胃不適、口腔潰瘍）；**隨餐或牛奶**服用增加吸收；嚴重腎衰竭（CrCl < 30）不用於預防。

### Mefloquine

- 長效 → **每週一次**預防：出發前 **2 週**、離開後 **4 週**；**懷孕可用**。
- **神經精神副作用**：失眠、惡夢、焦慮、憂鬱、**精神病**、癲癇；前庭症狀可能持續。
    - **禁忌**：精神疾病史、**癲癇**、心臟傳導異常。
- 東南亞（泰緬、泰柬邊境）抗藥。

### Quinine

- 舊藥；口服 Quinine + Doxycycline/Clindamycin 為替代處方。
- **Cinchonism**：**耳鳴**、聽力下降、頭痛、噁心、視力模糊。
- **低血糖**（刺激胰島素分泌）、**QT 延長**、溶血、血小板低下。
- IV Quinidine 已退出美國市場 → 嚴重瘧疾改用 IV Artesunate。
- Babesiosis：Quinine + Clindamycin（替代 Atovaquone + Azithromycin）。

## 其他抗原蟲藥（Other Antiprotozoals）

| 疾病 | 首選藥物 | 重點 |
|------|----------|------|
| **阿米巴（Entamoeba）** | **Metronidazole** → **Paromomycin** | Metronidazole 打組織內滋養體，**腸腔藥物**清除包囊 |
| **Giardia** | **Tinidazole** 單次、Metronidazole、Nitazoxanide | |
| **Cryptosporidium** | **Nitazoxanide**；HIV 者靠 **ART 恢復免疫** | 免疫正常者多自癒 |
| **Trichomonas** | Metronidazole | 性伴侶同治 |
| **[[感染科#Toxoplasma gondii\|Toxoplasma]]** | **Pyrimethamine + Sulfadiazine + Leucovorin** | 懷孕初期急性感染 → **Spiramycin** |
| Cyclospora、Cystoisospora | **TMP-SMX** | |
| **PJP**（黴菌，常一起記） | TMP-SMX；替代 **Pentamidine**、**Atovaquone** | |
| Babesia | **Atovaquone + Azithromycin** | |
| Leishmania | **L-AmB**（內臟型）、**Miltefosine**（口服） | Miltefosine 致畸 |
| Chagas | **Benznidazole**、Nifurtimox | |
| 非洲錐蟲病 | Fexinidazole（口服）、Suramin、Melarsoprol | Melarsoprol 腦病變 |

- Metronidazole、Tinidazole 見[[抗生素：破壞 DNA#Flagyl（Metronidazole）|Flagyl（Metronidazole）]]；Pyrimethamine、TMP-SMX 見[[抗生素：抑制葉酸合成|抑制葉酸合成]]。
- **Paromomycin**：Aminoglycoside，**口服不吸收** → 只作用在腸腔（包囊、Cryptosporidium 輔助）。
- **Pentamidine**：IV 或吸入；**低血糖**（胰島細胞破壞，之後可能糖尿病）、**胰臟炎**、腎毒性、低血壓、QT 延長。

## 驅蟲藥（Anthelmintics）

### Albendazole 與 Mebendazole

- 機轉：結合蟲體 **β-tubulin** → 阻止**微小管聚合** → 葡萄糖吸收受阻 → 蟲體死亡。
- **廣效線蟲**：
    - **蛔蟲、鉤蟲、鞭蟲**：單次或 3 天。
    - **蟯蟲**：單次 → **2 週後再吃一次**（殺新孵出的蟲）；**全家一起治療**。
- **Albendazole** 也治組織內感染（吸收較好）：
    - **神經囊尾蚴症**：Albendazole（± Praziquantel）+ **Dexamethasone**（減輕蟲死後的發炎）；**癲癇先控制**、先排除**眼睛囊尾蚴**（治療會造成眼內發炎）。
    - **包蟲囊腫**（Echinococcus）：手術或 PAIR 前後合併 Albendazole。
    - Toxocara、皮膚幼蟲移行症、Strongyloides（替代）。
- 副作用：
    - 短療程很少副作用（腸胃不適）。
    - 長期（囊尾蚴、包蟲）：**肝毒性**、**骨髓抑制**、掉髮 → 每 2 週驗 CBC、肝功能。
    - **懷孕第一孕期避免**（動物致畸）。

### Ivermectin

- 機轉：增強無脊椎動物神經肌肉的 **glutamate-gated Cl⁻ 通道** → 麻痺；人類此通道在血腦屏障內 → 安全。
- 適應症：
    - **Strongyloides 首選**（200 μg/kg × 1–2 天）。
        - **免疫抑制前**（類固醇、化療、移植）：有流行區暴露史 → **先篩檢或經驗性治療**，避免**過度感染症候群（hyperinfection）**。
        - HTLV-1 共同感染者風險高。
    - **[[皮膚科#疥瘡（Scabies）|疥瘡]]**：口服 200 μg/kg，**1–2 週後重複**；**結痂型疥瘡**合併外用 Permethrin。
    - **[[皮膚科#蝨病（Pediculosis）|頭蝨]]**（外用或口服）、Onchocerciasis（河盲症）。
- 注意：
    - **Loa loa 共同感染**（中西非）→ 大量微絲蟲死亡 → **腦病變**。
    - 懷孕、< 15 kg 兒童資料有限 → 避免。
    - 不用於 COVID-19（大型試驗無效）。

### Praziquantel

- 機轉：增加蟲體細胞膜 **Ca²⁺ 通透性** → 肌肉**強直收縮麻痺**、外皮破損。
- **扁蟲首選**：
    - **吸蟲**：**Schistosoma**、**[[感染科#吸蟲（Trematodes）|中華肝吸蟲（Clonorchis）]]**（台灣有食生淡水魚感染）、Paragonimus。
    - **絛蟲**：**腸道 Taenia**、Diphyllobothrium、Hymenolepis；神經囊尾蚴症（合併 Albendazole）。
- 例外：**Fasciola**（肝蛭）→ **Triclabendazole**。
- 副作用：頭暈、腹痛、嗜睡；**眼睛囊尾蚴症禁用**；強 CYP 誘導劑（Rifampin）使濃度大降 → 避免併用。

### 其他驅蟲藥

- **Pyrantel pamoate**：**nicotinic 受體致效劑** → 去極化**痙攣性麻痺**；蛔蟲、蟯蟲、鉤蟲；吸收少。
- **Diethylcarbamazine（DEC）**：**淋巴絲蟲病**；Loa loa（需小心大量死蟲反應）；**Onchocerciasis 禁用**（Mazzotti 反應）。
- **Niclosamide**：腸道絛蟲（不吸收）。
- **Triclabendazole**：**Fasciola** 首選。

## 疥瘡與頭蝨用藥（Scabicides & Pediculicides）

- **Permethrin**：鈉離子通道 → 神經麻痺。
    - **疥瘡**：**5% 乳膏**從頸部以下塗全身（嬰兒、老人包含頭皮臉部），8–14 小時後洗掉，**1–2 週後重複**。
    - **頭蝨**：1% 洗劑，7–10 天後重複；抗藥增加。
    - 懷孕、2 個月以上嬰兒可用。
- 疥瘡處置重點：
    - **同住者、密切接觸者同時治療**（不論有無症狀）。
    - 衣物、床單 **60°C 以上熱水**洗滌或密封 3 天以上。
    - **治療後搔癢可持續 2–4 週**（過敏反應），不代表治療失敗。
    - **長照機構、醫院群聚** → 口服 Ivermectin 集體治療、感染管制。
- **Lindane**：**神經毒性（癲癇）** → 已少用，兒童、癲癇病人禁用。
- Malathion（頭蝨，易燃）、Crotamiton、Benzyl benzoate（替代）。
