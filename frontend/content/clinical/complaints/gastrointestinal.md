## 腹痛

### 急性腹痛

#### 定義與分類

- **急性腹痛**：數小時至數天內發生的腹痛；**急腹症（acute abdomen）** 指需要緊急處置（常為手術）的急性腹痛。
- 依疼痛機轉：
    - **內臟痛（visceral）**：中空器官擴張或缺血 → 鈍痛、定位不清、位於中線（依胚胎來源：前腸 → 上腹、中腸 → 肚臍周圍、後腸 → 下腹）。
    - **體壁痛（parietal）**：壁層腹膜受刺激 → 銳痛、定位清楚、活動時加劇。
    - **轉移痛（referred）**：例如膽囊 → 右肩胛、脾臟破裂 → 左肩（**Kehr sign**）、腎結石 → 腹股溝/陰囊。
- 典型演變：闌尾炎先肚臍周圍內臟痛 → 數小時後轉移到右下腹體壁痛。

#### Red flags

- **血行動力學不穩定**（低血壓、心搏過速、意識改變）。
- **腹膜炎徵象**：rebound tenderness、guarding、**board-like rigidity**。
- **疼痛程度與理學檢查不成比例**（pain out of proportion）→ 腸繫膜缺血。
- 突發劇痛（數秒內達高峰）→ 穿孔、血管破裂、扭轉。
- 搏動性腹部腫塊 + 低血壓 + 腹痛/背痛 → **AAA 破裂**。
- 育齡女性腹痛 + 停經 → **子宮外孕**。
- 高齡、免疫低下、使用類固醇者：症狀與徵象輕微，**低估嚴重度的風險高**。

#### 依位置的鑑別診斷

| 位置 | 腹內原因 | 鑑別關鍵 |
|---|---|---|
| **右上腹** | 膽絞痛、急性膽囊炎、膽管炎、肝膿瘍、急性肝炎、十二指腸潰瘍穿孔 | Murphy sign、Charcot triad、超音波首選 |
| **上腹** | 消化性潰瘍、急性胰臟炎、胃炎、GERD、**下壁心肌梗塞**、主動脈剝離 | 胰臟炎痛往背部放射、前傾坐姿緩解；**上腹痛一律考慮 ECG** |
| **左上腹** | 脾梗塞、脾破裂、胰尾病變、胃潰瘍 | 外傷後 + 左肩痛 → 脾破裂 |
| **肚臍周圍** | 早期闌尾炎、小腸阻塞、腸繫膜缺血、腸胃炎、AAA | 腸繫膜缺血：AF 病史、疼痛不成比例 |
| **右下腹** | 闌尾炎、Crohn's disease、盲腸憩室炎、Meckel 憩室炎、腸繫膜淋巴腺炎 | McBurney point、Rovsing、psoas、obturator sign |
| **左下腹** | **乙狀結腸憩室炎**（西方最常見）、乙狀結腸扭轉、缺血性腸炎、UC | 台灣憩室較多在右側 |
| **下腹/恥骨上** | 膀胱炎、尿滯留、**子宮外孕**、PID、卵巢扭轉、卵巢囊腫破裂、子宮內膜異位症 | 女性一律驗孕、必要時骨盆腔檢查 |
| **腰側** | 腎結石、腎盂腎炎、腎梗塞 | 絞痛、輾轉難安、血尿；CVA knocking pain |
| **瀰漫性** | 穿孔合併腹膜炎、腸繫膜缺血、腸阻塞、腸胃炎、SBP | 腹膜炎者靜止不動；腎結石者坐立難安 |

- 腹部以外的原因（易漏）：
    - 心肺：**下壁心肌梗塞**、下葉肺炎、肺栓塞、心包膜炎。
    - 代謝內分泌：**DKA**、腎上腺危象、高血鈣、尿毒症。
    - 血液：鐮刀型貧血危象、**急性間歇性紫質症**、鉛中毒。
    - 其他：帶狀疱疹（出疹前）、睪丸扭轉、家族性地中海熱、腹壁疼痛、藥物（opioid withdrawal）。

#### 特殊族群

- **老年人**：發燒、白血球、腹膜徵象常不明顯；腸繫膜缺血、AAA、憩室炎、惡性腸阻塞比例高；死亡率明顯較高。
- **孕婦**：
    - 闌尾炎是**懷孕期最常見的非產科手術急症**，壓痛點隨子宮增大往上移。
    - 影像：超音波 → MRI（不含 gadolinium）；必要時 CT 仍可做，不應延誤診斷。
- **免疫低下**：除一般原因外，還要考慮 CMV 腸炎、neutropenic enterocolitis（typhlitis，化療後盲腸）、黴菌感染。

#### 問診與理學檢查

- OPQRST：發作方式（突發 vs 漸進）、位置與轉移、性質（絞痛 vs 持續痛）、放射、伴隨症狀、時間。
- 伴隨症狀：
    - 嘔吐先於腹痛 → 傾向腸胃炎；**腹痛先於嘔吐** → 傾向外科急症。
    - 未排便排氣 → 腸阻塞。
    - 發燒、黃疸 → 膽道感染。
    - 血尿 → 泌尿道結石。
- 病史：腹部手術史（沾黏）、AF/血管疾病（腸繫膜栓塞）、酒精/膽結石（胰臟炎）、NSAID/類固醇（潰瘍穿孔）、最後月經與性行為史。
- 理學檢查：
    - 生命徵象最優先。
    - 視診（腹脹、手術疤痕、Cullen/Grey Turner sign）→ 聽診（腸音亢進或消失）→ 觸診（從最不痛處開始）。
    - **疝氣好發處**（鼠蹊、股、臍）一定要檢查，避免漏掉嵌頓性疝氣。
    - 必要時肛門指診、骨盆腔檢查、睪丸檢查。

#### 檢查流程

- 基本檢驗：CBC/DC、電解質、BUN/Cr、血糖、肝功能、**lipase**、尿液分析、**育齡女性驗孕（urine/serum hCG）**；視情況 lactate、血液培養、ECG、troponin。
- 影像選擇：

| 臨床懷疑 | 首選影像 |
|---|---|
| 右上腹痛、膽道疾病 | **腹部超音波** |
| 右下腹痛（成人） | **腹部 CT（含顯影劑）** |
| 右下腹痛（兒童、孕婦） | 超音波 → 不確定再 MRI（孕婦）或 CT |
| 左下腹痛、憩室炎 | CT |
| 腎結石 | **Non-contrast CT**（孕婦、年輕人可先超音波） |
| 疑似穿孔 | **直立胸部 X 光**（橫膈下游離氣體）→ CT 更敏感 |
| 疑似腸阻塞 | 腹部 X 光（KUB）→ CT |
| 疑似腸繫膜缺血、AAA、主動脈剝離 | **CT angiography** |
| 血行動力學不穩定、懷疑 AAA 破裂或腹內出血 | 床邊超音波（FAST） |
| 疑似子宮外孕、卵巢扭轉 | 經陰道超音波（卵巢扭轉加 Doppler） |

- 急性胰臟炎診斷不需要 CT（症狀 + lipase ≥ 3 倍即可）；CT 用於診斷不確定或 :red[72 小時後]評估併發症。

#### 初步處置

- 不穩定者：ABC、兩條大口徑靜脈留置針、輸液復甦、交叉配血、會診外科。
- **NPO**；腸阻塞或持續嘔吐者放鼻胃管減壓。
- **及早止痛**：使用 opioid 止痛**不會**掩蓋腹膜徵象或延誤診斷。
- 懷疑腹內感染或穿孔 → 抽血液培養後給廣效抗生素（涵蓋 Gram 陰性桿菌與厭氧菌）。
- 不確定診斷且穩定者 → 留觀、重複腹部檢查（serial abdominal examination）。

:::pitfall
老年人或使用類固醇者腹痛 → 因為沒發燒、白血球正常、腹部柔軟就判斷不嚴重而讓病人離院 → 延誤腸繫膜缺血、穿孔、憩室炎的診斷，死亡率大增。這類病人的門檻要放低，寧可做 CT。
:::

:::pitfall
育齡女性下腹痛 → 沒有驗孕就以腸胃炎或泌尿道感染處理（或直接安排 CT）→ 漏掉子宮外孕破裂，或讓早期懷孕暴露於輻射。所有育齡女性腹痛先驗孕。
:::

### 慢性與反覆腹痛

#### 定義與 Alarm features

- 持續或反覆超過 **3 個月**的腹痛。
- **Alarm features**（有任一項 → 積極排除器質性疾病，安排內視鏡/影像）：
    - 年齡 ≥ 50 歲新發症狀。
    - 體重減輕、夜間痛醒、發燒。
    - 消化道出血、缺鐵性貧血。
    - 進行性吞嚥困難、持續嘔吐。
    - 腹部腫塊、淋巴結腫大。
    - 消化道癌症或 IBD 家族史。

#### 鑑別診斷

| 類別 | 疾病 | 鑑別關鍵 |
|---|---|---|
| 功能性 | **功能性消化不良**、**大腸激躁症（IBS）** | 符合 Rome IV、無 alarm features |
| 上消化道 | 消化性潰瘍、GERD、胃癌 | 與進食相關；十二指腸潰瘍空腹痛、進食緩解 |
| 膽胰 | 膽絞痛、**慢性胰臟炎**、胰臟癌 | 慢性胰臟炎：酒精、脂肪便、糖尿病、鈣化 |
| 腸道 | IBD、celiac disease、乳糖不耐、小腸細菌過度增生（SIBO） | 腹瀉、體重減輕、血便 |
| 血管 | **慢性腸繫膜缺血** | **餐後 15–60 分鐘腹痛（intestinal angina）→ 怕吃東西 → 體重減輕** |
| 代謝 | **急性間歇性紫質症（AIP）**、鉛中毒、DKA 反覆發作 | AIP：腹痛 + 神經精神症狀 + 深色尿 + 低血鈉 |
| 婦科 | 子宮內膜異位症、慢性 PID | 與月經週期相關 |
| 腹壁 | **前皮神經卡壓（ACNES）**、腹壁疝氣 | **Carnett sign 陽性** |
| 其他 | 家族性地中海熱、腹部偏頭痛（兒童） | FMF：週期性發燒 + 漿膜炎，colchicine 有效 |

- **Carnett sign**：病人平躺抬頭使腹肌收縮，壓痛**加劇或不變** → 腹壁來源；壓痛**減輕** → 腹腔內來源。
- **急性間歇性紫質症**：
    - Porphobilinogen deaminase 缺乏（AD），誘發因素：藥物（barbiturates、sulfonamides、抗癲癇藥）、禁食、酒精、月經。
    - 診斷：發作時 **urine porphobilinogen（PBG）↑**。
    - 治療：**hemin**、高劑量葡萄糖；停用誘發藥物。

#### 功能性腸胃疾病（Rome IV）

- 共同時間條件：診斷前 **6 個月**開始出現症狀，且最近 **3 個月**符合條件。
- **功能性消化不良**：餐後飽脹、早飽、上腹痛、上腹灼熱感（≥ 1 項），且**胃鏡無結構性病灶**。
    - 分為 postprandial distress syndrome 與 epigastric pain syndrome。
    - 治療：H. pylori 陽性先除菌 → PPI → 三環抗憂鬱劑或 prokinetics。
- **大腸激躁症（IBS）**：反覆腹痛平均 :red[每週 ≥ 1 天]，並符合下列 ≥ 2 項：
    - 與排便相關。
    - 伴隨排便頻率改變。
    - 伴隨糞便性狀改變。
- IBS 依主要糞便型態分為 IBS-C、IBS-D、IBS-M；詳見 [[消化內科#大腸激躁症（Irritable Bowel Syndrome, IBS）|大腸激躁症]]。

:::exam
功能性腸胃疾病的診斷前提是**沒有 alarm features**。題目若出現體重減輕、血便、貧血、50 歲以上新發症狀，就不能直接診斷 IBS 或功能性消化不良，下一步是內視鏡。
:::

## 上消化道症狀

### 噁心與嘔吐

#### 定義與分類

- **嘔吐（vomiting）**：胃內容物經口用力排出；**反流（regurgitation）**：不費力、無噁心，見於 GERD、achalasia、Zenker 憩室；**反芻（rumination）**：餐後將食物反流回口中再咀嚼吞下。
- 急性（< 1 週）vs 慢性（> 4 週）。

#### 依機轉的鑑別診斷

| 機轉 | 疾病 |
|---|---|
| 消化道阻塞 | 胃出口阻塞（潰瘍、胃癌）、小腸阻塞、腸扭轉、嵌頓性疝氣 |
| 消化道發炎 | 腸胃炎、闌尾炎、膽囊炎、胰臟炎、肝炎 |
| 動力異常 | **胃輕癱（gastroparesis）**、術後腸阻塞（ileus）、慢性腸假性阻塞 |
| 中樞神經 | **顱內壓上升**（腫瘤、出血、腦膜炎）、偏頭痛、前庭疾病（BPPV、Ménière）、暈車 |
| 代謝內分泌 | **DKA**、尿毒症、**高血鈣**、低血鈉、**腎上腺功能不全**、甲狀腺疾病 |
| 懷孕 | **妊娠嘔吐（morning sickness）**、妊娠劇吐、HELLP、妊娠急性脂肪肝 |
| 藥物與毒物 | 化療藥、opioid、**digoxin 中毒**、theophylline、酒精、抗生素 |
| 心肺 | **下壁心肌梗塞** |
| 其他 | **大麻素劇吐症候群**、週期性嘔吐症候群、心因性 |

#### 嘔吐物與時間的線索

- **膽汁性（綠色）**：阻塞位於 ampulla of Vater 以下；**新生兒膽汁性嘔吐 = 腸旋轉不良合併中腸扭轉，直到排除**。
- **非膽汁性、噴射狀**（2–8 週大嬰兒）→ [[小兒外科#肥厚性幽門狹窄（Hypertrophic Pyloric Stenosis, HPS）|肥厚性幽門狹窄]]。
- **糞臭味**：遠端小腸阻塞、胃結腸瘻管。
- **數小時前未消化的食物**：胃出口阻塞、胃輕癱、achalasia（反流）。
- **清晨嘔吐**：懷孕、**顱內壓上升**、尿毒症、酒精。
- **進食後立即**：心因性、幽門管潰瘍。
- 伴隨症狀：頭痛 + 視乳突水腫 → 顱內壓上升；眩暈 + 眼振 → 前庭；腹痛先於嘔吐 → 外科急症。

#### 特殊疾病

- **胃輕癱**：
    - 常見原因：**糖尿病**（最常見）、術後（迷走神經切斷）、特發性、病毒感染後。
    - 表現：早飽、餐後飽脹、嘔吐未消化食物。
    - 診斷：先排除機械性阻塞（胃鏡）→ **胃排空閃爍攝影**：:red[4 小時殘留 > 10%]（或 2 小時 > 60%）。
    - 治療：少量多餐、低脂低纖；血糖控制；**metoclopramide**（黑盒警告：tardive dyskinesia，避免使用超過 12 週）、erythromycin（短期，會快速耐受）。
- **大麻素劇吐症候群**：長期使用大麻 → 週期性劇吐；**熱水淋浴可緩解**為特徵；治療是戒大麻。
- **週期性嘔吐症候群**：刻板發作、間歇期完全正常；與偏頭痛相關。

#### 併發症

- **低氯、低鉀、代謝性鹼中毒**（contraction alkalosis）：
    - 尿液 Cl⁻ < 20 mEq/L（chloride-responsive）。
    - 嚴重時出現 **paradoxical aciduria**（為保留 Na⁺ 而排 H⁺ 與 K⁺）。
    - 治療：**生理食鹽水 + KCl**。
- 脫水、急性腎損傷。
- **Mallory-Weiss tear**（黏膜撕裂 → 吐血）、**Boerhaave syndrome**（食道全層破裂 → 胸痛、皮下氣腫、縱膈腔氣腫，Hamman crunch）。
- 吸入性肺炎。

#### 止吐劑選擇

| 類別 | 藥物 | 適用情境 | 注意事項 |
|---|---|---|---|
| **5-HT3 拮抗劑** | Ondansetron、granisetron | 化療、術後、腸胃炎 | **QT 延長**、便秘 |
| **D2 拮抗劑** | Metoclopramide、prochlorperazine、domperidone | 胃輕癱、偏頭痛 | 錐體外症狀；**腸阻塞禁用 metoclopramide**；domperidone 不通過 BBB，但 QT 延長 |
| H1 拮抗劑 | Meclizine、dimenhydrinate | **前庭性**、暈車 | 嗜睡、抗膽鹼 |
| NK1 拮抗劑 | Aprepitant | 化療（尤其**延遲性**嘔吐） | 與 5-HT3 + dexamethasone 合併 |
| 類固醇 | Dexamethasone | 化療、顱內壓上升 | — |
| Benzodiazepine | Lorazepam | **預期性**化療嘔吐 | — |
| 懷孕首選 | **Pyridoxine（B6）± doxylamine** | 妊娠嘔吐 | 無效再用 ondansetron 或 metoclopramide |

### 吞嚥困難

#### 定義與分類

- **吞嚥困難（dysphagia）**：食物從口腔到胃的通過受阻；**吞嚥痛（odynophagia）**：吞嚥時疼痛；**球感（globus）**：喉嚨異物感但吞嚥不受影響（功能性）。
- 第一步：區分**口咽型**與**食道型**。

| | 口咽型（oropharyngeal） | 食道型（esophageal） |
|---|---|---|
| 症狀 | **難以啟動吞嚥**、嗆咳、鼻腔逆流、吞完咳嗽 | 吞下數秒後**卡在胸骨後** |
| 常見原因 | **中風**、Parkinson、ALS、重症肌無力、肌炎、**Zenker 憩室**、頭頸癌 | 機械性阻塞、運動障礙 |
| 首選檢查 | **吞嚥攝影（videofluoroscopic swallow study）** | **胃鏡（EGD）** |

#### 食道型吞嚥困難的鑑別

- 只有**固體**困難 → **機械性阻塞**：
    - **進行性**：
        - **食道癌**：高齡、體重減輕、吸菸喝酒（鱗狀細胞癌）或 Barrett（腺癌）。
        - **消化性狹窄**：長期胃灼熱病史。
    - **間歇性**：
        - **Schatzki ring**（下食道環）：大塊食物卡住（steakhouse syndrome）。
        - **嗜酸性食道炎（EoE）**：年輕男性、過敏體質、食物嵌塞；胃鏡見環狀紋路與縱溝，切片 :red[≥ 15 eos/HPF]。
- **固體與液體**一開始都困難 → **運動障礙**：
    - 進行性 + 胃灼熱 → **硬皮症（systemic sclerosis）**：下食道括約肌無力。
    - 進行性 + 反流未消化食物 + 體重減輕 → **Achalasia**：鋇劑攝影 **bird's beak**；高解析食道壓力檢查確診。
    - 間歇性 + 胸痛 → **瀰漫性食道痙攣**：鋇劑攝影 corkscrew esophagus。
- 高齡 + 快速體重減輕 + achalasia 影像 → 懷疑**假性 achalasia**（賁門癌）→ 胃鏡、EUS、CT。

#### 吞嚥痛的鑑別

- **感染性食道炎**（免疫低下）：
    - Candida：白斑；吞嚥痛 + 口腔念珠菌 → 可經驗性治療 fluconazole。
    - **HSV**：小而淺的火山口狀潰瘍。
    - **CMV**：大而深的縱向潰瘍；治療 ganciclovir。
- **藥物性食道炎**：doxycycline/tetracycline、**KCl**、NSAID、**bisphosphonate**、鐵劑；與吞藥時水量不足、服藥後立即平躺有關。
- 腐蝕性食道炎、放射性食道炎。

#### 檢查流程

1. 口咽型 → 吞嚥攝影 + 神經學評估；食道型 → **胃鏡**（可同時切片、擴張）。
2. 懷疑近端病灶或 Zenker 憩室 → 可先做**鋇劑攝影**（盲目放胃鏡有穿孔風險）。
3. 胃鏡正常 → **高解析食道壓力檢查**（運動障礙的 gold standard）。

:::exam
吞嚥困難的考題重點在「固體 vs 固液皆有」與「進行性 vs 間歇性」兩個軸：只有固體 → 機械性；一開始固液都有 → 運動障礙。再用伴隨症狀（胃灼熱、體重減輕、胸痛）區分疾病。
:::

### 胸口灼熱與消化不良

#### 胸口灼熱（Heartburn）

- 典型 GERD 症狀：胸骨後灼熱感 + 酸水反流，餐後、平躺、彎腰時加劇。
- 無 alarm features → **PPI 經驗性治療 8 週**（試驗性治療兼診斷）。
- 需要胃鏡的情況：
    - Alarm features（吞嚥困難、體重減輕、出血、貧血、持續嘔吐）。
    - PPI 治療無效。
    - **Barrett 篩檢**：男性、長期 GERD 並合併多項危險因子（> 50 歲、白人、肥胖、吸菸、家族史）。
- PPI 無效、胃鏡正常 → **24 小時 pH-impedance 監測**（區分酸逆流、非酸逆流、功能性胃灼熱）。
- 非典型表現：慢性咳嗽、氣喘控制不佳、聲音沙啞、非心因性胸痛（**胸痛先排除心臟原因**）。

#### 消化不良（Dyspepsia）

- 上腹痛或上腹灼熱感為主（可伴隨餐後飽脹、早飽）。
- 處理流程：
    - **≥ 60 歲**或有 alarm features → **胃鏡**。
    - **< 60 歲**、無 alarm features → **H. pylori test-and-treat**（urea breath test 或糞便抗原）→ 陰性或除菌後仍有症狀 → PPI → 三環抗憂鬱劑或 prokinetics。
- 檢測 H. pylori 前：PPI 停 2 週、抗生素與鉍劑停 4 週，避免偽陰性。
- 台灣胃癌發生率高於西方，實務上胃鏡門檻常較寬。

## 排便異常

### 急性腹瀉

#### 定義與分類

- **腹瀉**：每天 ≥ 3 次稀便，或排便量 > 200 g/day。
- 依病程：**急性 < 14 天**、持續性 14–30 天、**慢性 > 30 天**（或 > 4 週）。
- 依型態：
    - **非發炎性（水瀉）**：小腸為主、大量水樣便、無發燒或輕微、無血；病原多為病毒、毒素型細菌。
    - **發炎性（痢疾）**：大腸為主、**血便或黏液便、發燒、裏急後重**、量少次數多。

#### 病原與潛伏期

| 潛伏期 | 病原 | 食物/情境 | 特點 |
|---|---|---|---|
| **1–6 小時** | **S. aureus**、**B. cereus**（嘔吐型） | 室溫放置的便當/沙拉；**炒飯** | **預先形成的毒素** → 嘔吐為主、很快緩解 |
| 8–16 小時 | C. perfringens、B. cereus（腹瀉型） | 大量烹煮後保溫的肉類 | 水瀉、腹痛 |
| 12–24 小時 | **Vibrio parahaemolyticus（腸炎弧菌）** | **生食海鮮** | 台灣常見的細菌性食物中毒 |
| 12–48 小時 | **Norovirus** | 群聚感染（學校、郵輪、安養機構） | 嘔吐 + 水瀉，傳染力極強，**酒精乾洗手效果差** |
| 6–72 小時 | **Salmonella**（non-typhoidal） | 雞蛋、家禽 | 發燒、腹瀉；嬰兒、老人、免疫低下者可菌血症 |
| 1–3 天 | **Shigella** | 人傳人，**極少菌量即可感染** | 痢疾、發燒；兒童可熱痙攣 |
| 2–5 天 | **Campylobacter** | 未熟家禽 | 痢疾；**之後可併發 Guillain-Barré syndrome** |
| 3–4 天 | **EHEC（O157:H7）** | 未熟牛絞肉 | 血便、**通常不發燒**；**HUS** |
| 1–3 週 | Giardia | 溪水、露營、旅遊 | 脂肪便、脹氣 |
| 不定 | **C. difficile** | **近期抗生素使用**、住院 | 見下方 |

- 其他：**霍亂**（米湯樣大量水瀉 → 嚴重脫水）、**Entamoeba histolytica**（痢疾、肝膿瘍）、Yersinia（假性闌尾炎）、旅行者腹瀉（ETEC 最常見）。

#### 需要進一步檢查的情況

- **糞便檢查（培養、病原分子檢測）**的時機：
    - 血便、高燒、嚴重脫水或需住院。
    - 症狀 > 7 天。
    - 免疫低下、高齡、群聚感染、食品從業人員。
- **C. difficile 檢測**：近 3 個月內使用抗生素或住院 > 3 天後出現 ≥ 3 次/天不成形便。
- 腹瀉 + 腹膜徵象或嚴重腹痛 → CT（排除缺血性腸炎、毒性巨結腸）。

#### 處置

- **補充水分與電解質**最重要：首選**口服補液鹽（ORS）**；嚴重脫水或無法口服 → 靜脈輸液。
- 止瀉劑：
    - **Loperamide**：可用於無發燒、非血便的成人水瀉。
    - **血便、發燒或懷疑 C. difficile 時避免使用** → 可能延長病程、誘發毒性巨結腸。
    - Bismuth subsalicylate：可用，會使糞便變黑。
- 經驗性抗生素：
    - **大多數不需要**。
    - 考慮的情況：嚴重痢疾、高燒、免疫低下、中重度旅行者腹瀉。
    - 首選 **azithromycin**（fluoroquinolone 抗藥性漸增）。
- **EHEC 避免抗生素** → 增加毒素釋放、**HUS 風險上升**。
- C. difficile 治療：**fidaxomicin 或口服 vancomycin**；fulminant（低血壓、休克、ileus、巨結腸）→ 口服 vancomycin + IV metronidazole，必要時大腸切除。詳見 [[消化內科#C. difficile 感染（CDI）|C. difficile 感染]]。

:::pitfall
血便、不發燒的急性腹瀉（懷疑 EHEC）→ 依一般腸胃炎給經驗性抗生素 → 細菌溶解釋出更多 Shiga toxin，增加 HUS（溶血性貧血、血小板低下、急性腎損傷）的風險。先送糞便檢查，支持療法為主，並追蹤 CBC 與腎功能。
:::

### 慢性腹瀉

#### 定義與分類

- 腹瀉 **> 4 週**。
- 依糞便特徵分三大類：

| 類型 | 特徵 | 代表疾病 |
|---|---|---|
| **水瀉（watery）** | 大量水樣便 | 分為滲透性與分泌性（見下） |
| **脂肪便（fatty）** | 油膩、惡臭、浮在水面、難沖掉、體重減輕 | **吸收不良**：慢性胰臟炎、celiac disease、SIBO、短腸症、膽汁酸缺乏 |
| **發炎性（inflammatory）** | 血便、黏液、發燒、腹痛 | **IBD**、缺血性腸炎、大腸癌、慢性感染（阿米巴、TB）、放射性腸炎 |

#### 水瀉：滲透性 vs 分泌性

- **糞便滲透壓差（stool osmotic gap）** = 290 − 2 ×（糞便 Na⁺ + K⁺）：
    - :red[> 125 mOsm/kg] → **滲透性**。
    - :red[< 50 mOsm/kg] → **分泌性**。
- **禁食試驗**：禁食後腹瀉停止 → 滲透性；持續 → 分泌性。

| | 滲透性（osmotic） | 分泌性（secretory） |
|---|---|---|
| 禁食 | **停止** | **持續**（夜間也會腹瀉） |
| 滲透壓差 | 大 | 小 |
| 原因 | **乳糖不耐**、含鎂瀉劑/制酸劑、sorbitol、lactulose、吸收不良 | 霍亂毒素、**VIPoma**、**類癌症候群**、gastrinoma、**microscopic colitis**、膽汁酸性腹瀉、刺激性瀉劑濫用、甲狀腺髓質癌 |

- **Microscopic colitis**：中老年女性慢性水瀉、**大腸鏡外觀正常**、需**隨機切片**（collagenous 或 lymphocytic）；與 NSAID、PPI、SSRI 相關；治療 budesonide。
- **詐病性腹瀉**：濫用瀉劑 → 大腸鏡見 **melanosis coli**（anthraquinone 類，如 senna）、低血鉀；檢測糞便中的瀉劑。

#### 脂肪便的評估

- 篩檢：糞便 **Sudan III 染色**。
- 定量：72 小時糞便脂肪 :red[> 7 g/day]（每日 100 g 脂肪飲食）。
- 鑑別胰臟性與小腸性：
    - **D-xylose 試驗**：小腸黏膜吸收不需胰酶 → 小腸疾病異常、胰臟功能不全正常。
    - **Fecal elastase < 200 μg/g** → 胰臟外分泌不足。
- Celiac disease：anti-tTG IgA（同時驗總 IgA）→ 十二指腸切片（villous atrophy）。

#### 檢查流程

1. 病史：糞便型態、夜間腹瀉（器質性）、體重減輕、旅遊、藥物（**metformin**、PPI、NSAID、colchicine、Mg 製劑）、乳製品、腹部手術史（迴腸切除 → 膽汁酸性腹瀉）、全身疾病（甲狀腺、糖尿病、HIV）。
2. 基本檢驗：CBC、電解質、白蛋白、TSH、CRP、celiac serology、糞便潛血/白血球/calprotectin、寄生蟲。
3. **Fecal calprotectin** 升高 → 傾向發炎性（IBD）→ 大腸鏡；正常 → 傾向 IBS 等功能性疾病。
4. 依類型安排：大腸鏡 + 隨機切片、胃鏡 + 十二指腸切片、影像、糞便電解質。

### 便秘

#### 定義（Rome IV 功能性便秘）

- 最近 3 個月符合（症狀始於 ≥ 6 個月前），下列 ≥ 2 項（各項指 > 25% 的排便）：
    - 用力解便。
    - 硬便或塊狀便。
    - 解不乾淨感。
    - 肛門直腸阻塞感。
    - 需要手指協助排便。
    - 自發性排便 :red[每週 < 3 次]。
- 不使用瀉劑時很少有稀便，且不符合 IBS 診斷。

#### 鑑別診斷

- **次發性原因**：
    - 藥物：**opioid**（最常見藥物原因）、抗膽鹼藥、三環抗憂鬱劑、**CCB（尤其 verapamil）**、鐵劑、鈣片、含鋁制酸劑、抗組織胺、5-HT3 拮抗劑。
    - 代謝內分泌：**甲狀腺功能低下**、**高血鈣**、低血鉀、糖尿病、懷孕。
    - 神經：Parkinson、多發性硬化症、脊髓損傷、自主神經病變。
    - 結構性：**大腸直腸癌**、狹窄、直腸脫垂、肛裂（疼痛而不敢解）。
- **原發性**（功能性）分三型：
    - **正常通過型**：最常見，與 IBS-C 重疊。
    - **慢速通過型**：大腸通過時間延長（Sitz marker 試驗）。
    - **排便協調障礙（dyssynergic defecation）**：解便時恥骨直腸肌與肛門括約肌未放鬆 → 肛門直腸壓力檢查、球囊排出試驗；治療**生物回饋（biofeedback）**。

#### 檢查

- 無 alarm features、無次發性原因 → 不需常規檢查，直接治療。
- Alarm features（血便、缺鐵性貧血、體重減輕、≥ 45–50 歲新發、大腸癌家族史、排便習慣急性改變）→ **大腸鏡**。
- 基本檢驗：CBC、血鈣、血糖、TSH。

#### 治療階梯

1. 增加膳食纖維（每日 20–30 g）與水分、運動、建立排便習慣（餐後利用胃結腸反射）。
2. **容積性瀉劑**：psyllium（需搭配足量水分；**慢速通過型與排便協調障礙效果差**）。
3. **滲透性瀉劑**：**PEG（首選）**、lactulose、氧化鎂（**腎功能不全者避免，高血鎂**）。
4. **刺激性瀉劑**：bisacodyl、senna（短期或救援使用）。
5. 促分泌劑（lubiprostone、linaclotide）、5-HT4 致效劑（prucalopride）。
- **Opioid 引起的便秘**：預防性給予瀉劑；頑固者用 **PAMORA**（methylnaltrexone、naloxegol）→ 只作用在腸道，不影響止痛。

:::exam
新發便秘先找次發性原因：藥物（opioid、verapamil、鐵劑、鈣片）、甲狀腺功能低下、高血鈣。高齡新發便秘或合併血便、貧血、體重減輕 → 大腸鏡排除大腸癌。
:::

## 消化道出血

### 上消化道出血

#### 定義與表現

- **Treitz 韌帶以上**的出血（食道、胃、十二指腸）。
- 表現：
    - **吐血（hematemesis）**：鮮紅血或**咖啡渣樣**嘔吐物。
    - **黑便（melena）**：柏油狀、惡臭；約 :red[50–100 mL] 血量即可造成。
    - **大量 UGIB 可表現為鮮血便**（約佔鮮血便病人的 10–15%）→ 通常合併血行動力學不穩定。
- 提示上消化道來源：**BUN/Cr 比值 > 30**（血液蛋白在小腸被吸收）、黑便、吐血。
- 黑便的鑑別：鐵劑、**鉍劑**也會使糞便變黑（但潛血陰性、非柏油狀）。

#### 鑑別診斷

| 原因 | 線索 |
|---|---|
| **消化性潰瘍**（最常見） | NSAID、aspirin、H. pylori、上腹痛 |
| **食道胃靜脈曲張** | **肝硬化**、酒精、B/C 型肝炎、脾腫大、腹水 |
| Mallory-Weiss tear | **劇烈嘔吐或乾嘔後**吐血（常見於酗酒） |
| 糜爛性食道炎/胃炎 | NSAID、酒精、壓力性潰瘍（ICU、燒傷、頭部外傷） |
| 腫瘤 | 胃癌、食道癌；慢性失血、體重減輕 |
| Dieulafoy lesion | 黏膜下異常粗大的動脈，大量但間歇性出血，常見於胃上部 |
| 血管擴張（angiodysplasia） | 高齡、CKD；**主動脈瓣狹窄（Heyde syndrome）** |
| **主動脈腸道瘻管** | **主動脈人工血管手術史** → 少量「前哨出血（herald bleed）」後大出血 |
| 膽道出血（hemobilia） | 肝臟切片、外傷後；**Quincke triad：右上腹痛 + 黃疸 + 消化道出血** |

#### 風險評估

- **Glasgow-Blatchford score（GBS）**：內視鏡前評估，用 BUN、Hb、收縮壓、心跳、黑便、暈厥、肝病、心衰竭計分。
    - :red[GBS 0–1] → 極低風險，可考慮門診處理。
- **Rockall score**：包含內視鏡發現，預測再出血與死亡率。
- 肝硬化病人出血 → 一律當成**靜脈曲張出血**處理，直到內視鏡證實不是。

#### 初步處置

1. **復甦**：
    - 兩條大口徑靜脈留置針、晶體輸液。
    - 大量吐血、意識不清 → 保護呼吸道（插管）後再做內視鏡。
2. **輸血**：
    - **限制性輸血**：:red[Hb < 7 g/dL] 才輸，目標 7–9 g/dL。
    - 心血管疾病者門檻 Hb < 8 g/dL。
    - 靜脈曲張出血過度輸血會**增加門脈壓、增加再出血**。
3. 停用抗凝血劑與抗血小板藥（評估栓塞風險）；必要時反轉凝血。
4. **非靜脈曲張出血**：
    - **IV PPI**。
    - **Erythromycin**：內視鏡前 30–120 分鐘 IV → 促進胃排空、改善視野。
5. **懷疑靜脈曲張出血（肝硬化）**：
    - **血管收縮劑**（terlipressin 或 octreotide）：內視鏡前就開始，持續 2–5 天。
    - **預防性抗生素**：ceftriaxone 1 g/day，最長 7 天 → 降低感染與再出血、改善存活。
6. **內視鏡時機**：
    - 一般 UGIB：:red[24 小時內]。
    - 靜脈曲張出血：:red[12 小時內]。
- 不建議常規放鼻胃管抽吸來判斷出血位置。

#### 內視鏡發現與後續（消化性潰瘍）

| Forrest 分級 | 內視鏡所見 | 未處理的再出血率 | 處置 |
|---|---|---|---|
| **Ia** | 噴射性出血（spurting） | 高（活動性出血約 55%） | **內視鏡止血** + 高劑量 PPI |
| **Ib** | 滲血（oozing） | 高 | **內視鏡止血** + 高劑量 PPI |
| **IIa** | 可見血管（visible vessel） | ~43% | **內視鏡止血** + 高劑量 PPI |
| IIb | 附著血塊（adherent clot） | ~22% | 考慮移除血塊後處理 + 高劑量 PPI |
| IIc | 平坦色素斑（flat pigmented spot） | ~10% | 口服 PPI |
| III | 乾淨基底（clean base） | ~5% | 口服 PPI，可早期出院 |

- 內視鏡止血：**不可只單獨注射 epinephrine**，需合併 thermal coagulation 或止血夾。
- 高風險病灶止血後：**IV PPI**（80 mg bolus → 8 mg/h，或間歇高劑量）持續 :red[72 小時] → 改口服。
- 檢測 H. pylori（急性出血時可能偽陰性，陰性需日後再驗）並除菌。
- 再出血 → **再做一次內視鏡** → 仍失敗 → **經導管動脈栓塞（TAE）** 或手術。
- 靜脈曲張出血：**內視鏡結紮（EVL）**（胃靜脈曲張用 cyanoacrylate）→ 失敗 → **balloon tamponade**（Sengstaken-Blakemore，最多 24 小時，作為過渡）→ **TIPS**；高風險者（Child-Pugh C 10–13 分，或 B 級合併活動性出血）考慮 72 小時內**早期 TIPS**。
- 詳見 [[消化內科#上消化道出血（Upper GI Bleeding）|上消化道出血]]、[[肝膽胰外科#食道靜脈曲張出血（Esophageal Variceal Bleeding）|食道靜脈曲張出血]]。

### 下消化道出血

#### 定義與表現

- **Treitz 韌帶以下**的出血。
- 表現：**鮮血便（hematochezia）**、暗紅色血便（右側大腸或小腸）、黑便（偶見於小腸或右側大腸緩慢出血）。
- 約 80% 自行停止。

#### 鑑別診斷

| 年齡層 | 常見原因 |
|---|---|
| 成人（尤其老年人） | **憩室出血**（最常見，無痛、大量）、**血管擴張**、**缺血性腸炎**（腹痛後血便）、大腸癌/息肉（慢性少量）、痔瘡、IBD、**息肉切除術後出血**（術後數天至 2 週）、放射性直腸炎 |
| 年輕成人 | 痔瘡、肛裂、IBD、感染性腸炎、Meckel 憩室 |
| 兒童 | **Meckel 憩室**（< 2 歲、無痛大量出血）、**腸套疊**（果醬樣便）、幼年型息肉、肛裂、感染性腸炎 |

- 依出血特徵：
    - **無痛 + 大量** → 憩室出血、血管擴張、Meckel 憩室。
    - **腹痛 + 血便** → 缺血性腸炎、IBD、感染性腸炎、腸套疊。
    - **只在衛生紙或糞便表面、解便時** → 痔瘡（無痛）、肛裂（劇痛）。
    - **合併排便習慣改變、貧血、體重減輕** → 大腸癌。

#### 檢查流程

1. 復甦與風險評估（同上消化道出血原則）。
2. **血行動力學不穩定的鮮血便 → 先排除 UGIB**（胃鏡）。
3. 穩定者 → 腸道準備後 **大腸鏡**（:red[24 小時內]），可同時診斷與止血。
4. 持續活動性出血、不穩定或大腸鏡無法執行 → **CT angiography**（偵測出血速率約 0.3–1 mL/min）→ 陽性 → **血管攝影 + 栓塞**（需約 0.5–1 mL/min）。
5. **Tc-99m 標記紅血球掃描**：最靈敏（約 0.1 mL/min），適合間歇性出血，但定位較差。
6. 以上皆無法控制 → 手術（術前盡量定位，避免盲目大腸次全切除）。

:::pitfall
血行動力學不穩定的大量鮮血便 → 直接認定是下消化道出血而先排大腸鏡或血管攝影 → 漏掉大量上消化道出血（例如十二指腸潰瘍），延誤止血。不穩定的鮮血便要先做胃鏡（或至少評估 BUN/Cr、肝硬化病史）。
:::

### 潛血與不明原因消化道出血

- **潛血（occult GI bleeding）**：糞便潛血陽性或**缺鐵性貧血**，但沒有肉眼可見的出血。
- **男性或停經後女性的缺鐵性貧血 → 一律做胃鏡 + 大腸鏡**（排除消化道惡性腫瘤）；同時驗 celiac serology。
- **不明原因消化道出血（obscure GI bleeding）**：胃鏡 + 大腸鏡皆正常，仍持續或反覆出血 → 多來自**小腸**：
    - 第一步：可考慮重做胃鏡/大腸鏡（第一次漏看）。
    - **膠囊內視鏡**：小腸首選；懷疑狹窄時先做 CT enterography（避免膠囊卡住）。
    - 發現病灶 → **氣囊小腸鏡**（double-balloon enteroscopy）切片或治療。
- 小腸出血依年齡：
    - < 40 歲：小腸腫瘤、**Meckel 憩室**（**Tc-99m pertechnetate scan**）、Crohn's disease。
    - > 40 歲：**血管擴張**（最常見）、NSAID 潰瘍、腫瘤。

## 肝膽相關徵象

### 黃疸

#### 定義

- 血清膽紅素 :red[> 2.5–3 mg/dL] 時肉眼可見，最先出現在**鞏膜**（舌下、手掌）。
- 第一步：區分**非結合型（間接）** 與**結合型（直接）** 膽紅素為主。
    - 直接膽紅素 < 15–20% 總量 → **非結合型高膽紅素血症**。
    - 直接膽紅素佔比較高 → **結合型高膽紅素血症**（肝細胞或膽汁鬱積）。
- 結合型膽紅素為水溶性 → 可由尿液排出 → **茶色尿**；膽道完全阻塞 → **灰白便**。

#### 非結合型（間接）高膽紅素血症

- **產生過多**：
    - **溶血**（LDH↑、haptoglobin↓、網狀紅血球↑、間接膽紅素通常 < 4–5 mg/dL）。
    - 無效紅血球生成（巨球性貧血、thalassemia）。
    - 大量血腫吸收。
- **攝取或結合減少**：
    - **Gilbert syndrome**、Crigler-Najjar syndrome。
    - 藥物（rifampin、probenecid）。
    - 新生兒生理性黃疸。

#### 結合型（直接）高膽紅素血症

- 先看肝功能型態：**R ratio** =（ALT / ALT 上限）÷（ALP / ALP 上限）：
    - **R ≥ 5** → **肝細胞型**。
    - **R ≤ 2** → **膽汁鬱積型**。
    - 2–5 → 混合型。
- **肝細胞型**：
    - **ALT > 1000 U/L**：急性病毒性肝炎、**缺血性肝炎**（休克肝，數天內快速下降）、**藥物（acetaminophen）**、急性膽管阻塞（短暫升高）、自體免疫肝炎、Wilson disease。
    - **AST/ALT > 2**（且 AST 很少 > 300–400）→ **酒精性肝病**。
    - 其他：慢性 B/C 型肝炎、脂肪肝、血色素沉著症。
- **膽汁鬱積型**：ALP↑ + **GGT↑**（ALP 升高但 GGT 正常 → 骨骼來源）。
    - 第一步：**腹部超音波**看膽管是否擴張（:red[CBD > 6 mm]；膽囊切除後可達 8–10 mm）。
    - **膽管擴張 → 肝外阻塞**：
        - **總膽管結石**：絞痛、膽管炎（**Charcot triad**：發燒 + 右上腹痛 + 黃疸）。
        - **胰頭癌、壺腹周圍癌**：**無痛性黃疸**、體重減輕；**Courvoisier sign**（可觸摸到不痛的腫大膽囊）。
        - 膽管癌、慢性胰臟炎狹窄、PSC、膽道術後狹窄。
        - 下一步：**MRCP**（診斷）、**EUS**（遠端小病灶、結石）、**ERCP**（治療：取石、放支架）。
    - **膽管未擴張 → 肝內膽汁鬱積**：
        - 藥物：amoxicillin-clavulanate、口服避孕藥、合成類固醇、chlorpromazine。
        - **原發性膽汁性膽管炎（PBC）**：中年女性、搔癢、**AMA 陽性**。
        - **原發性硬化性膽管炎（PSC）**：年輕男性、**UC**、MRCP 呈串珠狀。
        - 其他：敗血症、TPN、浸潤性疾病（類澱粉、淋巴瘤、肉芽腫）、**妊娠肝內膽汁鬱積**（第三孕期搔癢）、術後良性膽汁鬱積。

#### 遺傳性高膽紅素血症

| 疾病 | 型態 | 缺陷 | 特點 |
|---|---|---|---|
| **Gilbert syndrome** | 非結合型 | UGT1A1 活性降低 | 最常見；**禁食、壓力、感染時黃疸加劇**；良性、不需治療 |
| Crigler-Najjar type I | 非結合型 | UGT1A1 **完全缺乏** | 新生兒**核黃疸**；需肝臟移植 |
| Crigler-Najjar type II | 非結合型 | UGT1A1 部分缺乏 | **phenobarbital 有效** |
| **Dubin-Johnson syndrome** | 結合型 | **MRP2** 缺陷 | **肝臟外觀黑色**；良性 |
| Rotor syndrome | 結合型 | 肝細胞儲存缺陷 | 肝臟外觀正常；良性 |

:::exam
黃疸的考題幾乎都從「直接 vs 間接」開始，再用 ALT/ALP 型態與超音波（膽管有沒有擴張）一路分下去。無痛性黃疸 + Courvoisier sign → 胰頭或壺腹周圍惡性腫瘤；禁食後黃疸、其他肝功能正常的年輕人 → Gilbert syndrome。
:::

### 腹水

#### 評估

- 理學檢查：**shifting dullness**（約 1500 mL 以上才明顯）、fluid wave；超音波可偵測少量腹水。
- 分級：
    - Grade 1：僅超音波可見。
    - Grade 2：中度、腹部對稱膨大。
    - Grade 3：大量、腹部明顯膨脹緊繃。
- **診斷性腹水穿刺**時機：
    - 新發生的腹水。
    - 肝硬化合併腹水者**住院時**。
    - 臨床惡化（發燒、腹痛、肝性腦病變、腎功能惡化、消化道出血）。
- 凝血功能異常**不是**穿刺的禁忌，不需常規輸 FFP 或血小板；禁忌是 DIC、腹壁感染。

#### 腹水分析：SAAG

- **SAAG（serum-ascites albumin gradient）** = 血清白蛋白 − 腹水白蛋白。

| SAAG | 腹水總蛋白 | 原因 |
|---|---|---|
| **≥ 1.1 g/dL**（門脈高壓） | **< 2.5 g/dL** | **肝硬化**（最常見）、酒精性肝炎、大量肝轉移 |
| **≥ 1.1 g/dL** | **≥ 2.5 g/dL** | **心衰竭**、縮窄性心包膜炎、**Budd-Chiari syndrome**（早期）、SOS |
| **< 1.1 g/dL**（非門脈高壓） | ≥ 2.5 g/dL | **腹膜癌轉移**、**結核性腹膜炎**、胰臟性腹水、漿膜炎（SLE） |
| < 1.1 g/dL | < 2.5 g/dL | **腎病症候群**、蛋白質營養不良 |

- 其他腹水檢查：
    - **細胞數與分類**：PMN :red[≥ 250/mm³] → **自發性細菌性腹膜炎（SBP）**。
    - 培養：床邊直接打入血液培養瓶（提高陽性率）。
    - 細胞學：腹膜癌轉移（敏感度高）；肝癌造成的腹水細胞學常陰性。
    - **ADA**：> 40 U/L → 傾向結核性腹膜炎（淋巴球為主）。
    - **Amylase**：明顯升高 → 胰臟性腹水（胰管破裂）。
    - **Triglyceride > 200 mg/dL**（乳糜狀）→ **乳糜腹水**：淋巴瘤、淋巴管損傷、肝硬化。
    - 血性腹水：惡性腫瘤、外傷、HCC 破裂。

#### SBP vs 繼發性腹膜炎

- **SBP**：肝硬化腹水自發感染，**單一菌種**（E. coli、Klebsiella 最常見），症狀可很輕微（僅肝性腦病變或腎功能惡化）。
    - 治療：**第三代頭孢菌素**（cefotaxime 或 ceftriaxone）5 天 + **albumin**（第 1 天 1.5 g/kg、第 3 天 1 g/kg → 預防肝腎症候群）。
    - 預防：曾發生 SBP 者 → 長期口服預防（norfloxacin、ciprofloxacin 或 TMP-SMX）；肝硬化合併消化道出血 → ceftriaxone 短期預防。
- **繼發性腹膜炎**（腸穿孔、膿瘍）：**多種菌**（含厭氧菌）；**Runyon criteria**（符合 ≥ 2 項）：
    - 腹水總蛋白 > 1 g/dL。
    - 腹水葡萄糖 < 50 mg/dL。
    - 腹水 LDH > 血清正常上限。
    - 懷疑時 → CT 找感染源 → 外科處理。

#### 肝硬化腹水的治療

1. **限鈉**：每日 :red[< 2 g（88 mmol）]；不常規限水，**血鈉 < 125 mEq/L** 才限水。
2. **利尿劑**：**spironolactone : furosemide = 100 : 40**（維持此比例可減少血鉀異常），最大量 400 : 160 mg/day。
    - 體重下降目標：無周邊水腫 :red[≤ 0.5 kg/day]；有周邊水腫 ≤ 1 kg/day。
3. **大量腹水穿刺（LVP）**：放出 :red[> 5 L] 時補充 **albumin 6–8 g/L**（預防 paracentesis-induced circulatory dysfunction）。
4. **頑固性腹水** → 反覆 LVP、**TIPS**（禁忌：肝性腦病變、嚴重心衰竭、高 bilirubin）、**評估肝臟移植**。
5. 避免 NSAID；頑固性腹水者避免 ACEi/ARB。
- 詳見 [[消化內科#腹水（Ascites）|腹水]]。

### 肝脾腫大

#### 肝腫大

- 正常肝臟在鎖骨中線的上下徑約 6–12 cm；觸診時注意質地、邊緣、壓痛、表面結節、**搏動性**。
- 假性肝腫大：肺氣腫（橫膈下壓）、Riedel lobe。
- 鑑別：
    - **鬱血**：右心衰竭、三尖瓣逆流（**搏動性肝臟**）、縮窄性心包膜炎、**Budd-Chiari syndrome**（腹痛 + 肝腫大 + 腹水三徵）。
    - **浸潤**：脂肪肝、類澱粉沉積、肝醣儲積症、血色素沉著症、淋巴瘤/白血病、**肝癌或轉移**。
    - **發炎**：急性病毒性肝炎、酒精性肝炎、肝膿瘍。
    - 囊性：多囊肝、包蟲囊腫。
- 質地：硬且表面結節 → 肝硬化或腫瘤；柔軟且壓痛 → 急性肝炎、鬱血。

#### 脾腫大

- 正常脾臟**觸摸不到**；超音波長徑 :red[> 13 cm] 視為腫大。
- 理學檢查：左上腹觸診（右側臥）、Traube space 敲診變濁音、Castell sign。
- 依機轉鑑別：

| 機轉 | 疾病 |
|---|---|
| **鬱血（門脈高壓）** | **肝硬化**、門脈/脾靜脈栓塞、Budd-Chiari、右心衰竭 |
| **感染** | **EBV（傳染性單核球增多症）**、CMV、**感染性心內膜炎**、**瘧疾**、TB、黑熱病、HIV、傷寒 |
| 免疫 | SLE、**Felty syndrome**（RA + 脾腫大 + 中性球低下）、sarcoidosis |
| **血液腫瘤** | 淋巴瘤、白血病（**CML**、CLL、**hairy cell leukemia**）、骨髓纖維化、真性紅血球增多症 |
| 溶血（工作量增加） | 遺傳性球形紅血球症、thalassemia、自體免疫溶血 |
| 浸潤 | **Gaucher disease**、Niemann-Pick、類澱粉沉積 |

- **巨大脾腫大**（越過中線或延伸至骨盆腔）：**CML**、**骨髓纖維化**、**瘧疾**、黑熱病、**Gaucher disease**、hairy cell leukemia、淋巴瘤、重型 thalassemia。
- 併發症：**脾功能亢進**（全血球減少）、脾梗塞（左上腹痛、左肩痛）、脾破裂。
- **EBV 感染合併脾腫大** → 避免接觸性運動至少 :red[3–4 週]（脾破裂風險）。

#### 檢查流程

1. 病史與理學檢查：肝病危險因子、旅遊史、發燒、淋巴結腫大、心衰竭徵象。
2. 檢驗：CBC/DC + 血液抹片、肝功能、病毒性肝炎標記、EBV/CMV 血清學、LDH。
3. 影像：腹部超音波（肝實質、門脈血流、脾臟大小）→ CT。
4. 仍不明 → 骨髓檢查、肝臟切片；**脾臟切片出血風險高，很少做**。

## 其他腹部症狀

### 腹脹與腸阻塞

#### 腹脹的鑑別（6F）

- **Flatus**（氣體）：腸阻塞、ileus、吞氣、IBS、乳糖不耐、SIBO。
- **Fluid**（液體）：腹水。
- **Fat**（脂肪）：肥胖。
- **Feces**（糞便）：便秘、糞便嵌塞。
- **Fetus**（懷孕）。
- **Fatal growth**（腫瘤）：卵巢腫瘤、腹腔內腫瘤、巨大肝脾腫大。

#### 腸阻塞的鑑別

| | 小腸阻塞（SBO） | 大腸阻塞（LBO） |
|---|---|---|
| 最常見原因 | **術後沾黏**（無手術史 → **疝氣**） | **大腸癌**，其次為扭轉、憩室炎 |
| 嘔吐 | 早且多（近端阻塞更明顯） | 晚、可為糞臭 |
| 腹脹 | 較輕（近端阻塞） | 明顯 |
| X 光 | 中央、有環狀皺襞（valvulae conniventes）、**階梯狀氣液面** | 周邊、結腸袋（haustra） |

- **3-6-9 原則**（X 光擴張上限）：小腸 :red[3 cm]、結腸 :red[6 cm]、盲腸 :red[9 cm]。
- 機械性 vs 功能性：
    - **Ileus（麻痺性腸阻塞）**：術後、電解質（**低血鉀**、低血鎂）、opioid、腹膜炎、腹膜後出血；腸音減少或消失，小腸大腸皆擴張。
        - 術後腸蠕動恢復順序：小腸（數小時內）→ 胃（24–48 小時）→ 大腸（:red[48–72 小時]）。
    - **Ogilvie syndrome（急性結腸假性阻塞）**：住院、術後、重症老人；大腸明顯擴張無機械性阻塞。
        - 盲腸 :red[> 12 cm] → 穿孔風險。
        - 治療：保守 → **neostigmine**（需心電監測，備 atropine，注意心搏過緩）→ 大腸鏡減壓。
- 特殊類型：
    - **乙狀結腸扭轉**：老年、長期便秘、安養機構住民；X 光 **coffee bean sign**；無壞死 → 乙狀結腸鏡減壓。
    - **閉鎖性腸阻塞（closed loop）**：兩端都被阻塞 → 快速絞窄。
    - 膽石性腸阻塞（gallstone ileus）：高齡女性；**Rigler triad**（膽道積氣 + 小腸阻塞 + 異位結石）。

#### 絞窄（strangulation）的徵象

- 臨床：持續性劇痛（由絞痛轉為持續痛）、發燒、心搏過速、腹膜炎徵象、白血球上升、**lactate 上升**、代謝性酸中毒。
- CT：腸壁顯影減少、腸壁積氣（pneumatosis）、腸繫膜水腫、門脈積氣、閉鎖性腸環。
- **有任何絞窄徵象 → 緊急手術**，不可繼續保守治療。

#### 處置

1. **NPO + 鼻胃管減壓 + 靜脈輸液**、矯正電解質、記錄尿量。
2. **沾黏性部分阻塞**、無絞窄 → 保守治療：
    - **水溶性顯影劑**（Gastrografin）試驗：:red[24 小時內]到達結腸 → 保守治療成功率高（兼具治療效果）。
    - 保守治療 48–72 小時無改善 → 手術。
3. **完全阻塞、絞窄、嵌頓性疝氣、無手術史的 SBO（腹部「處女腹」）、大腸癌阻塞** → 手術（或支架作為過渡）。
- 詳見 [[消化內科#腸阻塞（Intestinal Obstruction）|腸阻塞]]、[[胃小腸外科#小腸阻塞（SBO）|小腸阻塞]]、[[大腸直腸外科#大腸扭轉（Volvulus）|大腸扭轉]]。

### 肛門直腸症狀

#### 肛門疼痛

| 疾病 | 特徵 | 處置 |
|---|---|---|
| **肛裂** | **解便時撕裂痛 + 便後持續疼痛**、少量鮮血；**後正中線**最常見 | 纖維、溫水坐浴、局部 nitrate/CCB → 慢性者 **lateral internal sphincterotomy** |
| **血栓性外痔** | 急性疼痛、肛緣藍紫色腫塊 | 發作 :red[48–72 小時內] → 切除；之後 → 保守治療 |
| **肛門膿瘍** | 持續性跳痛、發燒、局部紅腫熱痛 | **切開引流**（單用抗生素不足） |
| 嵌頓性內痔 | 脫出無法推回、劇痛 | 急診處理 |
| 一過性肛門痛（proctalgia fugax） | 突發、數秒至數分鐘、自行緩解 | 安撫、保守治療 |

- **非後正中線的肛裂**（側方）→ 要懷疑 **Crohn's disease**、TB、HIV、梅毒、肛門癌。

#### 肛門出血

- **無痛性鮮血**、滴在馬桶或沾在衛生紙 → **內痔**（最常見）。
- **疼痛 + 鮮血** → 肛裂。
- 中高齡、有 alarm features（排便習慣改變、貧血、體重減輕、家族史）→ **大腸鏡**，不能只歸因於痔瘡。
- 年輕、典型痔瘡出血 → 肛門鏡或軟式乙狀結腸鏡即可。

#### 其他

- **肛門搔癢**：衛生習慣、痔瘡、蟯蟲（兒童夜間搔癢 → **透明膠帶試驗**）、念珠菌、接觸性皮膚炎。
- **大便失禁**：產傷（括約肌受損）、神經病變、直腸脫垂、**糞便嵌塞合併溢出性腹瀉**（老人常見，誤以為腹瀉）。
- 詳見 [[大腸直腸外科#肛門疾病|肛門疾病]]。
