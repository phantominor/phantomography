## 摘要

鄭以信醫師門診時談到 2026 年 9 月 1 日上路的健保降血脂藥物給付新制：改依 ASCVD 風險分成六級，起始門檻等於治療目標，極高風險降到 55 mg/dL。新制和指引已經很接近，但仍有「要先過門檻才能開」「中低風險要先生活型態調整 3–6 個月」「階梯式用藥」「表一表二品項」這些差別。另外簡短提到成人疫苗 Shingrix 與 RSV。

## 降血脂藥物給付新制（2026/9/1 起）

- 這次是近年幅度最大的修正：從過去依「疾病名稱」給付，改成依 **ASCVD 風險等級**給付，向指引靠攏。
- 起始用藥門檻＝治療目標值。

### 六個風險等級

| 風險等級 | 代表族群 | 起始門檻（LDL-C） | 目標（LDL-C） |
|---|---|---|---|
| 極高風險 | 冠狀動脈疾病，再加上任一項：1 年內心肌梗塞、≥ 2 次心肌梗塞、多條血管阻塞、急性冠心症合併糖尿病、合併周邊動脈疾病或頸動脈狹窄；或周邊動脈疾病合併冠心病或頸動脈狹窄 | :red[≥ 55 mg/dL] | < 55 |
| 非常高風險 | 已確診的 ASCVD：急性冠心症、PCI、CABG、缺血性中風或 TIA、周邊動脈疾病（血管再通、肢體缺血或截肢）；或影像顯示血管狹窄 ≥ 50% | :red[≥ 70] | < 70 |
| 高風險 | 糖尿病、未透析的 CKD（UACR ≥ 30 mg/g 或 eGFR < 60 持續 ≥ 3 個月）、LDL-C ≥ 190、冠狀動脈鈣化分數（CAC）≥ 400，任一項 | ≥ 100 | < 100 |
| 中風險 | 2 項危險因子 | ≥ 115 | < 115 |
| 低風險 | 1 項危險因子 | ≥ 130 | < 130 |
| 0 項危險因子 | 無 | ≥ 160 | < 160 |

- 計算的心血管危險因子：
    - 高血壓。
    - 年齡：男 ≥ 45 歲、女 ≥ 55 歲。
    - 早發性冠心病家族史：一等親男性 < 55 歲、女性 < 65 歲發病。
    - HDL-C 偏低：男 < 40、女 < 50 mg/dL。
    - 吸菸。
    - 代謝症候群（5 項符合 3 項，算 1 項危險因子）。

:::verify
筆記原文貼的「極高風險」定義是「2 年內發生第二次重大血管事件、ASCVD 合併多血管病變、糖尿病合併多重標的器官損傷」，和下面來源整理的條文定義不同；上表依來源（引用健保署「藥品給付規定」修訂對照表第 2.6 節）。0 項危險因子的門檻，部落格寫 ≥ 160、新聞寫「高於 160」。申報前以健保署公告的給付規定原文為準。
:::

### 健保新制與指引的差異

| | 指引（Guideline） | 健保給付（NHI） |
|---|---|---|
| 核心問題 | 病人要降到多少，心血管效益最大 | 健保什麼時候開始給付、給付哪一顆藥 |
| 起始 | The lower, the better；高風險病人未達標就可以開藥，基線已偏低（例如 65 → 50）仍鼓勵強化 | 起始門檻＝目標值，**一定要先抽血達門檻才能開**，不能預防性申報 |
| 生活型態調整 | 強調，但醫師評估風險高時開藥較有彈性 | **中、低風險與 0 項危險因子**：初次給付前要有 3–6 個月的飲食、運動調整紀錄，複查仍未達標才能開 |
| 合併治療 | 極高、非常高風險預期單用 statin 不夠（需降 > 50%）時，可以一開始就 statin + ezetimibe | 原則上階梯式：先中、高強度 statin，足量或最大耐受劑量仍未達標，或有耐受不良紀錄，才加或換 ezetimibe、PCSK9 抑制劑 |

- Ezetimibe 加藥前的觀察期：由 3 個月縮短為 6–8 週（少數品項仍需 3 個月）。

### 申報實務

- **藥碼雙軌制**：給付放寬伴隨藥價調整協議，只有配合調價的品項（依健保代碼與品名，不是依成分）適用新制「表一」；其他品項仍照較嚴格的舊制「表二」。開藥前確認院內的 statin 或複方是否在表一。
- **追蹤抽血**：
    - 開始或調整治療後 6–8 週（或 1–3 個月）追蹤。
    - 達標後：極高、非常高、高風險每 6 個月；中、低風險每 6–12 個月。
    - 急性發作住院的極高、非常高風險病人，入院 24 小時內完成血脂檢驗。
- **中低風險族群**：病歷要寫清楚 3–6 個月生活型態調整的衛教紀錄，並有前後兩次抽血報告對照，避免被抽審核刪。

## 成人疫苗

- Shingrix（帶狀疱疹重組疫苗）、RSV。
- RSV 的預防分成**單株抗體**與**疫苗**兩種。

:::supplement
- Shingrix：重組次單位疫苗，50 歲以上（或 18 歲以上免疫低下）打 2 劑，間隔 2–6 個月，保護力約 90%。見[[家庭醫學科#成人疫苗|成人疫苗]]。
- RSV：
    - 單株抗體（被動免疫）：nirsevimab（Beyfortus，長效、一季一劑）、palivizumab（Synagis，每月一劑）。用在嬰幼兒，保護第一個 RSV 季。
    - 疫苗（主動免疫）：Arexvy（GSK）、Abrysvo（Pfizer）。用在 60 歲以上（部分適應症擴及 50–59 歲高風險者）；Abrysvo 也可在孕期 32–36 週接種，抗體經胎盤保護新生兒。
:::
