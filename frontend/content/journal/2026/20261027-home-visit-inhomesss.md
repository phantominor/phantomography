## 摘要

薛復宸醫師的居家整合醫學個案報告與討論，用 IMHOMELESS（INHOMESSS）的架構評估居家個案。到病人家裡看診，除了疾病本身，還要看功能、營養、居家環境、照顧者、用藥、安全、靈性與可用的服務，這些是門診看不到、卻決定病人能不能在家生活的事。

## INHOMESSS 評估架構

- 課堂用 IMHOMELESS 的架構分析居家個案。

:::supplement
- INHOMESSS 是家庭醫學居家訪視（house call）常用的評估清單，由早期的 INHOME 擴充而來，美國家庭醫師學會（AAFP）的居家訪視回顧文章都用它當檢核表。
- 九個面向：

| 字母 | 面向 | 評估內容 |
|---|---|---|
| **I** | Impairments / Immobility（失能與活動） | ADL、IADL；行走、移位、上下樓梯的能力；輔具使用 |
| **N** | Nutrition（營養） | 打開冰箱和櫥櫃看有沒有食物、是否過期；誰買菜煮飯；體重變化、咀嚼吞嚥 |
| **H** | Home environment（居家環境） | 住家格局、樓梯與電梯、浴廁、照明、整潔與衛生 |
| **O** | Other people（其他人） | 主要照顧者是誰、照顧負荷與支持系統；家庭關係與社會網絡 |
| **M** | Medications（用藥） | 把家裡所有藥（含成藥、保健食品、中藥）拿出來核對；服藥順從性、藥物保存、重複與過期用藥 |
| **E** | Examination（身體檢查） | 生命徵象與身體檢查，在病人熟悉的環境裡觀察真實的功能表現 |
| **S** | Safety（安全） | 跌倒危險（地毯、雜物、門檻、扶手）、用火用電、煙霧偵測器、熱水溫度；虐待與疏忽的跡象 |
| **S** | Spiritual health（靈性） | 宗教信仰、生命意義、對疾病與死亡的看法、末期醫療意願 |
| **S** | Services（服務） | 已經使用與還能連結的資源：長照服務、居家護理、居家復健、喘息服務、交通接送 |

- 和門診的老年評估（CGA）互補：CGA 用量表評估病人本身（見[[家庭醫學科#老年評估（CGA, Comprehensive Geriatric Assessment）|老年評估]]），INHOMESSS 多了環境、照顧者、服務這些只有到家裡才看得到的面向。
- M 的用藥核對對應[[家庭醫學科#多重用藥（Polypharmacy）|多重用藥]]的處理；S 的居家安全對應[[家庭醫學科#跌倒|跌倒]]預防；O 的家庭功能可以搭配[[家庭醫學科#家庭 APGAR（Family APGAR）|家庭 APGAR]]。
:::

:::verify
課堂的名稱是 IMHOMELESS，筆記只寫了標題，各字母對應的面向沒有記下來。上表是文獻常見的 INHOMESSS 版本；講者版本若多了或換了某些字母（例如 L、E），請對照投影片補上。
:::

## 台灣的居家醫療

:::supplement
- 健保「居家醫療照護整合計畫」（2016 年起）依病人需要分三個照護階段，由同一個團隊依病情轉換：
    - 居家醫療：因失能或疾病特性外出就醫不便的病人。
    - 重度居家醫療：需要較密集醫療處置的病人，例如使用呼吸器、管路照護。
    - 安寧療護：末期病人，見[[家庭醫學科#台灣安寧照護模式|台灣安寧照護模式]]。
- 收案條件：失能或疾病特性導致外出就醫不便，且有明確的醫療需求。
:::

:::verify
居家醫療照護整合計畫的收案條件與各階段的定義，引用前以健保署公告的計畫內容為準。
:::
